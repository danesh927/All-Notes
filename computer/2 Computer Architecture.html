🏛️ ಕಂಪ್ಯೂಟರ್ ಸಂರಚನೆ (Computer Architecture) - ಮಾಸ್ಟರ್ ನೋಟ್ಸ್

ವಾನ್ ನ್ಯೂಮನ್ ವಿನ್ಯಾಸ + ಇನ್‌ಪುಟ್/ಔಟ್‌ಪುಟ್ + CPU (ALU, CU, 7 ರೆಜಿಸ್ಟರ್‌ಗಳು) + ಮೆಮೊರಿ ಪಿರಮಿಡ್ + ಸಿಸ್ಟಮ್ ಬಸ್ (100% ಸಚಿತ್ರ ಕೈಪಿಡಿ)

📐 ವಾನ್ ನ್ಯೂಮನ್ ವಿನ್ಯಾಸ ⌨️ 1 & 4. ಇನ್‌ಪುಟ್ & ಔಟ್‌ಪುಟ್ 🧠 2. CPU (ALU & CU) 🗂️ ರೆಜಿಸ್ಟರ್‌ಗಳು (7 ವಿಧ) 💾 3. ಮೆಮೊರಿ ಘಟಕ 🛣️ 5. ಸಿಸ್ಟಮ್ ಬಸ್ 🔥 ಹೆಚ್ಚುವರಿ ಪರೀಕ್ಷಾ ಅಂಶಗಳು 🎯 45 MCQs ಕ್ವಿಜ್ ಪುಟ ➔
📐 ಮೂಲ ಪರಿಕಲ್ಪನೆ: ವಾನ್ ನ್ಯೂಮನ್ ವಿನ್ಯಾಸ (Von Neumann Architecture - 1945) Stored Program Concept

ಇಂದಿನ ಬಹುತೇಕ ಎಲ್ಲಾ ಆಧುನಿಕ ಕಂಪ್ಯೂಟರ್‌ಗಳು 1945 ರಲ್ಲಿ ಜಾನ್ ವಾನ್ ನ್ಯೂಮನ್ (John Von Neumann) ರವರು ಪರಿಚಯಿಸಿದ ವಿನ್ಯಾಸವನ್ನು ಆಧರಿಸಿವೆ. ಇದನ್ನು "ಸ್ಟೋರ್ಡ್ ಪ್ರೋಗ್ರಾಮ್ ಕಾನ್ಸೆಪ್ಟ್" (Stored Program Concept) ಎಂದು ಕರೆಯಲಾಗುತ್ತದೆ. ಇದರ ಪ್ರಕಾರ, ಡೇಟಾ (Data) ಮತ್ತು ಅದನ್ನು ಸಂಸ್ಕರಿಸುವ ಸೂಚನೆಗಳು (Instructions) ಎರಡನ್ನೂ ಒಂದೇ ಮೆಮೊರಿಯಲ್ಲಿ (Main Memory - RAM) ಶೇಖರಿಸಿಡಲಾಗುತ್ತದೆ.

🖼️ ಕಂಪ್ಯೂಟರ್ ಸಂರಚನೆಯ ಸಮಗ್ರ ಬ್ಲಾಕ್ ಡಯಾಗ್ರಾಮ್ (Animated Von Neumann Block Diagram)

⌨️ 1. ಇನ್‌ಪುಟ್ ಘಟಕ (Input Unit) ಮತ್ತು 🖥️️ 4. ಔಟ್‌ಪುಟ್ ಘಟಕ (Output Unit) ಬೈನರಿ ಪರಿವರ್ತನೆ
🖼️ ಚಿತ್ರ: ಇನ್‌ಪುಟ್ ಡೇಟಾ ➔ ಬೈನರಿ ಪರಿವರ್ತನೆInput Unit

1. ಇನ್‌‌ಪುಟ್ ಘಟಕ (Input Unit)

  • ಕಾರ್ಯ: ಬಳಕೆದಾರರಿಂದ ದತ್ತಾಂಶವನ್ನು (Data) ಮತ್ತು ಸೂಚನೆಗಳನ್ನು ಸ್ವೀಕರಿಸಿ, ಅದನ್ನು ಕಂಪ್ಯೂಟರ್‌ಗೆ ಅರ್ಥವಾಗುವ ಭಾಷೆಗೆ (ಬೈನರಿ ಭಾಷೆ - 0 ಮತ್ತು 1) ಪರಿವರ್ತಿಸುವ ಕೆಲಸವನ್ನು ಇನ್‌ಪುಟ್ ಘಟಕ ಮಾಡುತ್ತದೆ.
  • ಪ್ರಮುಖ ಇನ್‌ಪುಟ್ ಸಾಧನಗಳು: ಕೀಬೋರ್ಡ್ (Keyboard), ಮೌಸ್ (Mouse), ಸ್ಕ್ಯಾನರ್ (Scanner), ಬಾರ್ ಕೋಡ್ ರೀಡರ್ (BCR), ಒಎಂಆರ್ (OMR - Optical Mark Reader), ಮೈಕ್ರೊಫೋನ್ (Microphone), ಜಾಯ್‌ಸ್ಟಿಕ್, ವೆಬ್‌ಕ್ಯಾಮ್.
🎯 ಪರೀಕ್ಷಾ ಅಂಶ: ಮನುಷ್ಯನ ಭಾಷೆಯನ್ನು ಕಂಪ್ಯೂಟರ್‌ನ ಯಂತ್ರ ಭಾಷೆಗೆ (0 & 1) ಬದಲಾಯಿಸುವ ಘಟಕ = ಇನ್‌ಪುಟ್ ಘಟಕ.
🖼️ ಚಿತ್ರ: ಮಾನಿಟರ್ (ಸಾಫ್ಟ್ ಕಾಪಿ) & ಪ್ರಿಂಟರ್ (ಹಾರ್ಡ್ ಕಾಪಿ)Output Unit

4. ಔಟ್‌ಪುಟ್ ಘಟಕ (Output Unit)

  • ಕಾರ್ಯ: CPU ನಿಂದ ಸಂಸ್ಕರಿಸಲ್ಪಟ್ಟ ಯಂತ್ರ ಭಾಷೆಯ (0 & 1) ಫಲಿತಾಂಶವನ್ನು, ಮನುಷ್ಯರಿಗೆ ಅರ್ಥವಾಗುವ ಭಾಷೆಗೆ (ಚಿತ್ರ, ಅಕ್ಷರ, ಧ್ವನಿ) ಪರಿವರ್ತಿಸಿ ನೀಡುವ ಘಟಕ.
  • ಪ್ರಮುಖ ಔಟ್‌ಪುಟ್ ಸಾಧನಗಳು:
    • ಮಾನಿಟರ್ (Monitor / VDU): ಪರದೆಯ ಮೇಲೆ ತೋರಿಸುವ ತಾತ್ಕಾಲಿಕ ಪ್ರತಿ ಅಂದರೆ ಸಾಫ್ಟ್ ಕಾಪಿ (Soft Copy) ನೀಡುತ್ತದೆ.
    • ಪ್ರಿಂಟರ್ (Printer) & ಪ್ಲಾಟರ್ (Plotter): ಕಾಗದದ ಮೇಲೆ ಮುದ್ರಿತ ಶಾಶ್ವತ ಪ್ರತಿ ಅಂದರೆ ಹಾರ್ಡ್ ಕಾಪಿ (Hard Copy) ನೀಡುತ್ತದೆ.
    • ಸ್ಪೀಕರ್ (Speaker), ಪ್ರೊಜೆಕ್ಟರ್ (Projector).
🎯 ಪರೀಕ್ಷಾ ಅಂಶ: ಸಾಫ್ಟ್ ಕಾಪಿ = ಮಾನಿಟರ್ | ಹಾರ್ಡ್ ಕಾಪಿ = ಪ್ರಿಂಟರ್.
🧠 2. ಕೇಂದ್ರ ಸಂಸ್ಕರಣಾ ಘಟಕ (CPU - Central Processing Unit) ಕಂಪ್ಯೂಟರ್‌ನ ಮೆದುಳು (Brain of Computer)

ಇನ್‌ಪುಟ್ ಮೂಲಕ ಬಂದ ದತ್ತಾಂಶವನ್ನು ಸಂಸ್ಕರಿಸುವುದು CPU ನ ಮುಖ್ಯ ಕೆಲಸ. ಮೈಕ್ರೋಪ್ರೊಸೆಸರ್ (Microprocessor) ಎಂಬ ಚಿಪ್ ಈ ಕೆಲಸವನ್ನು ಮಾಡುತ್ತದೆ. CPU ಒಳಗೆ ಪ್ರಮುಖವಾಗಿ 3 ಉಪ-ಘಟಕಗಳಿವೆ: A) ALU, B) CU, ಮತ್ತು C) Registers.

🖼️ ಚಿತ್ರ: ALU (ಗಣಿತ + ತಾರ್ಕಿಕ) ➔ ಅಕ್ಯುಮುಲೇಟರ್ಕಂಪ್ಯೂಟರ್‌ನ ಲೆಕ್ಕಿಗ

A. ಅಂಕಗಣಿತ ಮತ್ತು ತಾರ್ಕಿಕ ಘಟಕ (ALU - Arithmetic Logic Unit)

  • ಮೂಲ ವಿವರಣೆ: ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ನಡೆಯುವ ಎಲ್ಲಾ ಗಣಿತದ ಲೆಕ್ಕಾಚಾರಗಳು ಮತ್ತು ತಾರ್ಕಿಕ ತೀರ್ಮಾನಗಳನ್ನು ವಾಸ್ತವಿಕವಾಗಿ ನಿರ್ವಹಿಸುವ ಸ್ಥಳವೇ (Actual Execution of Instructions) ಈ ALU.
  • 1. ಅಂಕಗಣಿತ ವಿಭಾಗ (Arithmetic Section): ಕೂಡುವುದು (+), ಕಳೆಯುವುದು (-), ಗುಣಿಸುವುದು (×), ಮತ್ತು ಭಾಗಿಸುವುದು (÷). ಎಷ್ಟೇ ಸಂಕೀರ್ಣ ಸಮೀಕರಣಗಳಿದ್ದರೂ ಈ ನಾಲ್ಕು ಮೂಲ ಕ್ರಿಯೆಗಳ ಪುನರಾವರ್ತನೆಯಿಂದಲೇ ಉತ್ತರ ಕಂಡುಹಿಡಿಯುತ್ತದೆ.
  • 2. ತಾರ್ಕಿಕ ವಿಭಾಗ (Logic Section):
    • ಹೋಲಿಕೆಗಳು (Comparisons): ದೊಡ್ಡದು (>), ಚಿಕ್ಕದು (<), ಸಮ (=), ಸಮವಲ್ಲ (≠) ಪರಿಶೀಲನೆ.
    • ತಾರ್ಕಿಕ ಕಾರ್ಯಾಚರಣೆಗಳು: AND, OR, NOT ಲಾಜಿಕ್ ಗೇಟ್ ಬಳಸಿ True/False ನಿರ್ಧಾರ (ಉದಾ: ಪಾಸ್‌ವರ್ಡ್ ಸರಿ ಇದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸುವುದು).
  • ALU ಕೆಲಸ ಮಾಡುವ ವಿಧಾನ: CU ಮೆಮೊರಿಯಿಂದ (RAM) ಡೇಟಾ ತಂದು 'ರೆಜಿಸ್ಟರ್‌ಗಳಲ್ಲಿ' ಇಡುತ್ತದೆ ➔ ALU ಲೆಕ್ಕಾಚಾರ ಮಾಡುತ್ತದೆ ➔ ಬಂದ ಫಲಿತಾಂಶವನ್ನು ತಕ್ಷಣವೇ 'ಅಕ್ಯುಮುಲೇಟರ್' (Accumulator) ಎಂಬ ವಿಶೇಷ ರೆಜಿಸ್ಟರ್‌ನಲ್ಲಿ ತಾತ್ಕಾಲಿಕವಾಗಿ ಶೇಖರಿಸಿಡುತ್ತದೆ.
🎯 ಪರೀಕ್ಷಾ ಅಂಶಗಳು: ವಾಸ್ತವಿಕ ಡೇಟಾ ಪ್ರೊಸೆಸಿಂಗ್ ನಡೆಯುವ ಸ್ಥಳ = ALU | ಫಲಿತಾಂಶ ಹಿಡಿದಿಡುವ ರೆಜಿಸ್ಟರ್ = Accumulator | ALU ಕಂಟ್ರೋಲ್ ಯೂನಿಟ್ (CU) ಆದೇಶದಂತೆ ಮಾತ್ರ ಕೆಲಸ ಮಾಡುತ್ತದೆ.
🖼️ ಚಿತ್ರ: Fetch ➔ Decode ➔ Execute ➔ Storeನರಮಂಡಲ / ಟ್ರಾಫಿಕ್ ಪೊಲೀಸ್

B. ನಿಯಂತ್ರಣ ಘಟಕ (CU - Control Unit)

  • ಮೂಲ ವಿವರಣೆ: ಕಂಪ್ಯೂಟರ್‌ನ ವ್ಯವಸ್ಥಾಪಕ (Manager) ಅಥವಾ ಮೇಲ್ವಿಚಾರಕ (Supervisor). ಇದು ಕಂಪ್ಯೂಟರ್‌ನ 'ನರಮಂಡಲ' (Nervous System) ಮತ್ತು 'ಟ್ರಾಫಿಕ್ ಪೊಲೀಸ್' (Traffic Police) ಆಗಿದೆ.
  • ವಿಶೇಷ ಪರೀಕ್ಷಾ ಸೂಚನೆ: CU ಸ್ವತಃ ಯಾವುದೇ ಗಣಿತ ಲೆಕ್ಕಾಚಾರ ಅಥವಾ ಡೇಟಾ ಸಂಸ್ಕರಣೆ ಮಾಡುವುದಿಲ್ಲ; ಕೇವಲ ನಿರ್ದೇಶಿಸುತ್ತದೆ ಮತ್ತು 'ಟೈಮಿಂಗ್ & ಕಂಟ್ರೋಲ್ ಸಿಗ್ನಲ್' ಕಳುಹಿಸುತ್ತದೆ.
  • ಯಂತ್ರ ಚಕ್ರ (Machine / Instruction Cycle ಕ್ರಮ):
    1. Fetch (ತರುವುದು): RAM ಮೆಮೊರಿಯಿಂದ ಸೂಚನೆ ಪಡೆಯುವುದು.
    2. Decode (ಸಂಕೇತ ಬಿಡಿಸುವುದು): ಸೂಚನೆಯ ಅರ್ಥ ತಿಳಿದುಕೊಳ್ಳುವುದು.
    3. Execute (ಕಾರ್ಯಗತಗೊಳಿಸುವುದು): ALU ಗೆ ಆಜ್ಞೆ ನೀಡಿ ಕೆಲಸ ಮಾಡಿಸುವುದು.
    4. Store (ಉಳಿಸುವುದು): ಫಲಿತಾಂಶವನ್ನು ಮೆಮೊರಿಯಲ್ಲಿ ಶೇಖರಿಸುವುದು.
  • CU ನಲ್ಲಿರುವ ಪ್ರಮುಖ ರೆಜಿಸ್ಟರ್‌ಗಳು: PC (Program Counter) ಮತ್ತು IR (Instruction Register).
🎯 ಪರೀಕ್ಷಾ ಅಂಶ: ಕಂಪ್ಯೂಟರ್‌ನ ನರಮಂಡಲ ಮತ್ತು ಟ್ರಾಫಿಕ್ ಪೊಲೀಸ್ = Control Unit (CU). ಯಂತ್ರ ಚಕ್ರದ ಕ್ರಮ: Fetch ➔ Decode ➔ Execute ➔ Store.
🗂️ C. ರೆಜಿಸ್ಟರ್‌ಗಳು (CPU Registers) - ಅತ್ಯಂತ ವೇಗದ ಮೆಮೊರಿ ಅಡುಗೆಯವನ ಉದಾಹರಣೆ + 7 ವಿಧಗಳು

👨‍🍳 ಸುಲಭವಾಗಿ ನೆನಪಿಟ್ಟುಕೊಳ್ಳಲು 'ಅಡುಗೆಯವನ' (Chef) ಉದಾಹರಣೆ:

ಕಲ್ಪಿಸಿಕೊಳ್ಳಿ, CPU ಒಬ್ಬ ಅಡುಗೆಯವನು (Chef). ಆತನಿಗೆ ಬೇಕಾದ ತರಕಾರಿಗಳು (Data) ದೊಡ್ಡ ಉಗ್ರಾಣದಲ್ಲಿ (Hard Disk) ಇವೆ. ಅಲ್ಲಿಂದ ತಂದು ಆತ ಅಡುಗೆಮನೆಯ ಫ್ರಿಡ್ಜ್‌ನಲ್ಲಿ (RAM) ಇಡುತ್ತಾನೆ. ಆದರೆ ಈಗಲೇ ಒಲೆಯ ಮೇಲೆ ಬೇಯುತ್ತಿರುವ ಅಡುಗೆಗೆ ಹಾಕಲು, ಆತನ ಕೈಗೆಟುಕುವಂತೆ ಪಕ್ಕದಲ್ಲೇ ಇರುವ ಚಿಕ್ಕ ತಟ್ಟೆಗಳೇ 'ರೆಜಿಸ್ಟರ್‌ಗಳು' (Registers)! ಅಂದರೆ ಇದು ಕಂಪ್ಯೂಟರ್ ಮೆದುಳಿನ (CPU) ಜೇಬಿನಲ್ಲಿರುವ ಪುಟ್ಟ 'ನೋಟ್‌ಪ್ಯಾಡ್' ಇದ್ದಂತೆ.

🖼️ ಚಿತ್ರ: ಫ್ಲಿಪ್-ಫ್ಲಾಪ್ (Flip-Flop) ಮತ್ತು ಬಿಟ್ ಸಂಗ್ರಹZero Wait State

ತಾಂತ್ರಿಕ ಹಿನ್ನೆಲೆ & ಪರೀಕ್ಷಾ ಗುಣಲಕ್ಷಣಗಳು

  • ಫ್ಲಿಪ್-ಫ್ಲಾಪ್ (Flip-Flop): ರೆಜಿಸ್ಟರ್ ಎಂಬುದು ಫ್ಲಿಪ್-ಫ್ಲಾಪ್‌ಗಳ ಗುಂಪು. ಒಂದು ಫ್ಲಿಪ್-ಫ್ಲಾಪ್ ಕೇವಲ 1-ಬಿಟ್ (0 ಅಥವಾ 1) ಡೇಟಾ ಸಂಗ್ರಹಿಸುವ ಎಲೆಕ್ಟ್ರಾನಿಕ್ ಸರ್ಕ್ಯೂಟ್ (ಮನೆಯ ಲೈಟ್ ಸ್ವಿಚ್ ಇದ್ದಂತೆ).
  • ಅತ್ಯಂತ ವೇಗದ ಮೆಮೊರಿ (Fastest Memory):
    👉 ವೇಗದ ಕ್ರಮಾಂಕ: Registers > Cache > RAM > ROM > Hard Disk.
    ಇದು ಶೂನ್ಯ ಕಾಯುವಿಕೆ (Zero wait state) ಹೊಂದಿರುತ್ತದೆ.
  • ವರ್ಡ್ ಸೈಜ್ (Word Size): 32-ಬಿಟ್ ಅಥವಾ 64-ಬಿಟ್ ಎಂಬುದು ಡೇಟಾ ಚಲಿಸುವ ರಸ್ತೆಯ ಅಗಲವಿದ್ದಂತೆ. 64-ಬಿಟ್ ರೆಜಿಸ್ಟರ್ ಒಮ್ಮೆಗೆ 64 ಬಿಟ್ ಡೇಟಾ ಪ್ರೊಸೆಸ್ ಮಾಡುತ್ತದೆ.
  • ಸ್ಥಿತಿ (Volatility) & ಸ್ಥಳ: ಇದು ತಾತ್ಕಾಲಿಕ (Volatile) ಮೆಮೊರಿ (ಪವರ್ ಆಫ್ ಆದರೆ ಅಳಿಸುತ್ತದೆ) ಮತ್ತು CPU ಚಿಪ್ ಒಳಗಡೆಯೇ ಬೆಸೆದುಕೊಂಡಿರುತ್ತದೆ.
🖼️ ಚಿತ್ರ: ಪೋಸ್ಟ್‌ಮ್ಯಾನ್ ಉದಾಹರಣೆ (MAR vs MDR)7 Types of Registers

ಪ್ರಮುಖ ರೆಜಿಸ್ಟರ್‌ಗಳ ಸಂಕ್ಷಿಪ್ತ ಹೋಲಿಕೆ

  • ACC (Accumulator): ಕ್ಯಾಲ್ಕುಲೇಟರ್ ಪರದೆಯ ಮೇಲಿನ ಒಟ್ಟು ಮೊತ್ತ (Running Total).
  • PC (Program Counter): ಬ್ಯಾಂಕಿನಲ್ಲಿ "ಮುಂದಿನ ಟೋಕನ್ ನಂಬರ್ ಯಾರು?" ಎಂದು ನೆನಪಿಸುವ ಯಂತ್ರ (Next Instruction Address).
  • IR (Instruction Register): ಕೆಲಸಗಾರನ ಕೈಯಲ್ಲಿರುವ 'ಪ್ರಸ್ತುತ' ಓದುತ್ತಿರುವ ಆಜ್ಞಾ ಪತ್ರ (Current Running Instruction).
  • MAR (Memory Address Register): ಪೋಸ್ಟ್‌ಮ್ಯಾನ್ ಕವರ್ ಮೇಲಿನ 'ವಿಳಾಸದ ಚೀಟಿ'.
  • MDR (Memory Data Register): ಪೋಸ್ಟ್‌ಮ್ಯಾನ್ ತಂದ ಬಾಕ್ಸ್ ಒಳಗಿರುವ 'ಅಸಲು ವಸ್ತು' (Parcel).

📋 ರೆಜಿಸ್ಟರ್‌ಗಳ ಎಲ್ಲಾ ವಿಧಗಳು, ತಾಂತ್ರಿಕ ಕೆಲಸ ಮತ್ತು ಸರಳ ಉದಾಹರಣೆಗಳ ಕೋಷ್ಟಕ:

ರೆಜಿಸ್ಟರ್ ಹೆಸರು ತಾಂತ್ರಿಕ ಕೆಲಸ (Technical Function) ಸರಳ ಉದಾಹರಣೆ (Easy Analogy)
1. ಅಕ್ಯುಮುಲೇಟರ್ (Accumulator - ACC) ALU ಮಾಡುವ ಎಲ್ಲಾ ಗಣಿತ ಲೆಕ್ಕಾಚಾರಗಳ ಮಧ್ಯಂತರ ಮತ್ತು ಅಂತಿಮ ಫಲಿತಾಂಶಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ. ಕ್ಯಾಲ್ಕುಲೇಟರ್‌ನಲ್ಲಿ 5+5+5 ಹೊಡೆಯುವಾಗ ಪರದೆಯ ಮೇಲೆ ಕಾಣುವ ಒಟ್ಟು ಮೊತ್ತ (Running Total).
2. ಪ್ರೋಗ್ರಾಮ್ ಕೌಂಟರ್ (Program Counter - PC) 'ಮುಂದಿನ ಬಾರಿ' (Next Instruction) ಯಾವ ಸೂಚನೆಯನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸಬೇಕು ಎಂಬುದರ ವಿಳಾಸವನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ. ಬ್ಯಾಂಕಿನಲ್ಲಿ ಕೌಂಟರ್‌ನಲ್ಲಿ ಕುಳಿತವನಿಗೆ "ಮುಂದಿನ ಟೋಕನ್ ನಂಬರ್ ಯಾರು?" ಎಂದು ತೋರಿಸುವ ಯಂತ್ರ.
3. ಇನ್ಸ್‌ಟ್ರಕ್ಷನ್ ರೆಜಿಸ್ಟರ್ (Instruction Register - IR) CPU 'ಪ್ರಸ್ತುತ' (Current running instruction) ಯಾವ ಸೂಚನೆಯನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುತ್ತಿದೆಯೋ ಅದನ್ನು ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ. ಕೆಲಸಗಾರನೊಬ್ಬ ಪ್ರಸ್ತುತ ತನ್ನ ಕೈಯಲ್ಲಿ ಹಿಡಿದು ಓದುತ್ತಿರುವ ಆಜ್ಞಾ ಪತ್ರ (Task sheet).
4. ಮೆಮೊರಿ ಅಡ್ರೆಸ್ ರೆಜಿಸ್ಟರ್ (MAR) CPU ಗೆ ಬೇಕಾದ ಡೇಟಾ RAM ನ ಯಾವ ಜಾಗದಲ್ಲಿದೆ (ವಿಳಾಸ/Address) ಎಂಬುದನ್ನು CU ಗೆ ತಿಳಿಸುತ್ತದೆ. ಪೋಸ್ಟ್‌‌ಮ್ಯಾನ್ ಕೈಲಿರುವ ಕವರ್ ಮೇಲಿನ 'ವಿಳಾಸದ ಚೀಟಿ'.
5. ಮೆಮೊರಿ ಡೇಟಾ ರೆಜಿಸ್ಟರ್ (MDR / MBR) ಮೆಮೊರಿಯಿಂದ ಬಂದ ಡೇಟಾ ಅಥವಾ ಮೆಮೊರಿಗೆ ಹೋಗಬೇಕಾದ ಅಸಲು ಡೇಟಾವನ್ನು ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ. ಪೋಸ್ಟ್‌ಮ್ಯಾನ್ ತಂದಿರುವ ಬಾಕ್ಸ್ ಒಳಗಿರುವ 'ಅಸಲು ವಸ್ತು' (Parcel).
6. ಸಾಮಾನ್ಯ ಉದ್ದೇಶದ ರೆಜಿಸ್ಟರ್ (GPR - R1, R2) ಪ್ರೊಸೆಸಿಂಗ್ ನಡೆಯುವಾಗ ಡೇಟಾವನ್ನು ತಾತ್ಕಾಲಿಕವಾಗಿ ಇಟ್ಟುಕೊಳ್ಳಲು ALU ಇವುಗಳನ್ನು ಬಳಸುತ್ತದೆ. ಲೆಕ್ಕ ಮಾಡುವಾಗ ಮುಖ್ಯ ಹಾಳೆಯ ಪಕ್ಕದಲ್ಲಿ ಗೀಚಲು ಬಳಸುವ 'ರಫ್ ವರ್ಕ್' (Rough work) ಹಾಳೆ.
7. ಶಿಫ್ಟ್ ರೆಜಿಸ್ಟರ್‌ಗಳು (Shift Registers) ಬೈನರಿ ಬಿಟ್‌ಗಳನ್ನು ಎಡಕ್ಕೆ ಅಥವಾ ಬಲಕ್ಕೆ ಚಲಿಸುವಂತೆ (Shift) ಮಾಡಿ ತ್ವರಿತ ಗುಣಾಕಾರ/ಭಾಗಾಕಾರ ನಿರ್ವಹಿಸುತ್ತವೆ. 25 ನ್ನು 10 ರಿಂದ ಗುಣಿಸುವಾಗ ಮಗ್ಗಿ ಹೇಳದೆ ಪಕ್ಕದಲ್ಲಿ ಸೊನ್ನೆ ಸೇರಿಸಿ 250 ಮಾಡುವ ಶಾರ್ಟ್‌ಕಟ್.
🆕 8. ಫ್ಲಾಗ್ / ಸ್ಟೇಟಸ್ ರೆಜಿಸ್ಟರ್ (Flag Register / PSW) ALU ಲೆಕ್ಕಾಚಾರದ ನಂತರ ಫಲಿತಾಂಶ ಶೂನ್ಯವಾಗಿದೆಯೇ (Zero), ಮೈನಸ್ ಆಗಿದೆಯೇ (Sign) ಅಥವಾ ಮಿತಿ ಮೀರಿದೆಯೇ (Overflow/Carry) ಎಂದು ಸೂಚಿಸುತ್ತದೆ. ವಾಹನದ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿರುವ ವಾರ್ನಿಂಗ್ ಇಂಡಿಕೇಟರ್ ಲೈಟ್‌ಗಳು.
💾 3. ಮೆಮೊರಿ ಘಟಕ (Memory / Storage Unit) & ವೇಗದ ಪಿರಮಿಡ್ Registers > Cache > RAM > HDD
🖼️ ಚಿತ್ರ: ಮೆಮೊರಿ ವೇಗದ ಪಿರಮಿಡ್ (Memory Hierarchy)Very Important

A. ಪ್ರಾಥಮಿಕ ಮೆಮೊರಿ (Primary / Main Memory)

  • ಇದು ನೇರವಾಗಿ CPU ಸಂಪರ್ಕದಲ್ಲಿರುತ್ತದೆ:
  • 1. RAM (Random Access Memory): ಪ್ರಸ್ತುತ ನಡೆಯುತ್ತಿರುವ ಕೆಲಸಗಳ ಡೇಟಾ ಇಟ್ಟುಕೊಳ್ಳುತ್ತದೆ. ವಿದ್ಯುತ್ ಹೋದ ತಕ್ಷಣ ಡೇಟಾ ಅಳಿಸಿಹೋಗುತ್ತದೆ. ಆದ್ದರಿಂದ ಇದನ್ನು Volatile Memory (ತಾತ್ಕಾಲಿಕ/ಅಸ್ಥಿರ ಮೆಮೊರಿ) ಎನ್ನುತ್ತಾರೆ.
  • 2. ROM (Read Only Memory): ಕಂಪ್ಯೂಟರ್ ಆನ್ ಆಗಲು ಬೇಕಾದ ಮೂಲ ಸೂಚನೆಗಳನ್ನು (Booting / BIOS) ತಯಾರಕರು ಮೊದಲೇ ತುಂಬಿರುತ್ತಾರೆ. ವಿದ್ಯುತ್ ಹೋದರೂ ಡೇಟಾ ಅಳಿಸುವುದಿಲ್ಲ. ಆದ್ದರಿಂದ ಇದು Non-Volatile Memory (ಶಾಶ್ವತ/ಸ್ಥಿರ ಮೆಮೊರಿ).
🖼️ ಚಿತ್ರ: CPU ಮತ್ತು RAM ನಡುವೆ ಇರುವ ಕ್ಯಾಶ್ ಮೆಮೊರಿSRAM ವೇಗವರ್ಧಕ

B. ದ್ವಿತೀಯಕ ಮೆಮೊರಿ & C. ಕ್ಯಾಶ್ ಮೆಮೊರಿ

  • B. ದ್ವಿತೀಯಕ ಮೆಮೊರಿ (Secondary Memory): ಭವಿಷ್ಯದ ಬಳಕೆಗಾಗಿ ಅಪಾರ ಪ್ರಮಾಣದ ಡೇಟಾವನ್ನು ಶಾಶ್ವತವಾಗಿ (Non-Volatile) ಸಂಗ್ರಹಿಸಲು ಬಳಸಲಾಗುತ್ತದೆ. ಉದಾಹರಣೆ: Hard Disk (HDD), Solid State Drive (SSD), CD/DVD, Pen Drive.
  • C. ಕ್ಯಾಶ್ ಮೆಮೊರಿ (Cache Memory): ಇದು CPU ಮತ್ತು RAM ನ ನಡುವೆ ಇರುವ ಅತಿ ವೇಗದ ಮೆಮೊರಿ. CPU ಗೆ ಪದೇ ಪದೇ ಬೇಕಾಗುವ ಡೇಟಾವನ್ನು ಇದು ಇಟ್ಟುಕೊಳ್ಳುತ್ತದೆ, ಇದರಿಂದ ಕಂಪ್ಯೂಟರ್ ವೇಗ ಹೆಚ್ಚಾಗುತ್ತದೆ.
🎯 ಪರೀಕ್ಷಾ ವೇಗದ ಕ್ರಮ: Registers > Cache Memory > Main Memory (RAM) > Secondary Memory (SSD/HDD).
🛣️ 5. ಸಿಸ್ಟಮ್ ಬಸ್ (System Bus) - ಕಂಪ್ಯೂಟರ್ ಒಳಗಿನ 'ರಾಷ್ಟ್ರೀಯ ಹೆದ್ದಾರಿ' Data Bus + Address Bus + Control Bus

ಮೂಲ ವಿವರಣೆ: ಸಿಸ್ಟಮ್ ಬಸ್ ಎಂಬುದು ಮದರ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿರುವ ಎಲೆಕ್ಟ್ರಾನಿಕ್ ತಂತಿಗಳ (Electronic Wires / Pathways) ಗುಂಪಾಗಿದೆ. ಇದನ್ನು ಕಂಪ್ಯೂಟರ್ ಒಳಗಿನ 'ರಾಷ್ಟ್ರೀಯ ಹೆದ್ದಾರಿ' (National Highway) ಎನ್ನಬಹುದು. ಊರುಗಳ (CPU, RAM, I/O) ನಡುವೆ ವಾಹನಗಳು (ಡೇಟಾ) ಓಡಾಡಲು ಈ ರಸ್ತೆಗಳೇ ಆಧಾರ.

🎬 ಲೈವ್ ಅನಿಮೇಷನ್: ಸಿಸ್ಟಮ್ ಬಸ್‌ನ 3 ಹೆದ್ದಾರಿಗಳು (ಚಲನೆಯ ದಿಕ್ಕು ಗಮನಿಸಿ)

1. ಡೇಟಾ ಬಸ್ (Data Bus)

  • ತಾಂತ್ರಿಕ ಕೆಲಸ: CPU ಮತ್ತು ಮೆಮೊರಿ ಅಥವಾ ಇತರ ಸಾಧನಗಳ ನಡುವೆ ವಾಸ್ತವಿಕ ದತ್ತಾಂಶವನ್ನು (Actual Data) ಸಾಗಿಸುವ ಕೆಲಸ ಮಾಡುತ್ತದೆ.
  • ಚಲನೆಯ ದಿಕ್ಕು: ಇದು ದ್ವಿಮುಖ (Bi-directional) ಮಾರ್ಗವಾಗಿದೆ. ಡೇಟಾ CPU ನಿಂದ ಮೆಮೊರಿಗೆ ಹೋಗಬಹುದು ಮತ್ತು ಮೆಮೊರಿಯಿಂದ CPU ಗೂ ಬರಬಹುದು.
  • ಸರಳ ಉದಾಹರಣೆ: ರಸ್ತೆಯಲ್ಲಿ ಪ್ರಯಾಣಿಕರನ್ನು ಮತ್ತು ಸರಕುಗಳನ್ನು ಹೊತ್ತೊಯ್ಯುವ ನೈಜ ಬಸ್ಸುಗಳು/ಲಾರಿಗಳು (Two-way road).

2. ಅಡ್ರೆಸ್ ಬಸ್ (Address Bus)

  • ತಾಂತ್ರಿಕ ಕೆಲಸ: ಮೆಮೊರಿಯಲ್ಲಿ ಡೇಟಾ ಎಲ್ಲಿದೆ ಅಥವಾ ಎಲ್ಲಿಗೆ ಹೋಗಬೇಕು ಎಂಬ 'ವಿಳಾಸವನ್ನು' (Memory Location) ಮಾತ್ರ ಹೊತ್ತೊಯ್ಯುತ್ತದೆ.
  • ಚಲನೆಯ ದಿಕ್ಕು: ಇದು ಏಕಮುಖ (Uni-directional) ಮಾರ್ಗವಾಗಿದೆ. ವಿಳಾಸವು ಯಾವಾಗಲೂ CPU ನಿಂದ (ನಿರ್ದಿಷ್ಟವಾಗಿ MAR ನಿಂದ) ಮೆಮೊರಿಯ ಕಡೆಗೆ ಮಾತ್ರ ಹರಿಯುತ್ತದೆ.
  • ಸರಳ ಉದಾಹರಣೆ: ವಾಹನ ಹೋಗಬೇಕಾದ ಜಾಗ ತೋರಿಸುವ 'ಮೈಲಿಗಲ್ಲು' (Milestone) ಅಥವಾ GPS ವಿಳಾಸ.

3. ಕಂಟ್ರೋಲ್ ಬಸ್ (Control Bus)

  • ತಾಂತ್ರಿಕ ಕೆಲಸ: CPU ನ ಕಂಟ್ರೋಲ್ ಯೂನಿಟ್ (CU) ನಿಂದ ಹೊರಡುವ ನಿಯಂತ್ರಣ ಮತ್ತು ಟೈಮಿಂಗ್ ಸಿಗ್ನಲ್‌ಗಳನ್ನು (Read / Write signals) ಇತರ ಭಾಗಗಳಿಗೆ ತಲುಪಿಸುತ್ತದೆ.
  • ಸರಳ ಉದಾಹರಣೆ: ಹೆದ್ದಾರಿಯಲ್ಲಿ ವಾಹನ ನಿಯಂತ್ರಿಸುವ 'ಟ್ರಾಫಿಕ್ ಸಿಗ್ನಲ್'.
  • ಪರೀಕ್ಷಾ ಅಂಶಗಳು (Bus Width & RAM ಸಾಮರ್ಥ್ಯ):
    • ಬಸ್ ಅಗಲ (Bus Width): ಏಕಕಾಲಕ್ಕೆ ಎಷ್ಟು ಬಿಟ್ ಡೇಟಾ ಚಲಿಸಬಹುದು ಎಂಬುದು (32-bit ಬಸ್ = 32 ತಂತಿಗಳ ಹೈವೇ).
    • ಮೆಮೊರಿ ಸಾಮರ್ಥ್ಯ ನಿರ್ಧಾರ: 'ಅಡ್ರೆಸ್ ಬಸ್'ನ ಅಗಲವು ಕಂಪ್ಯೂಟರ್‌ನ ಗರಿಷ್ಠ RAM ಸಾಮರ್ಥ್ಯವನ್ನು ನಿರ್ಧರಿಸುತ್ತದೆ! (32-bit Address Bus = ಗರಿಷ್ಠ $2^{32}$ = 4 GB RAM ಮಾತ್ರ ಬೆಂಬಲಿಸುತ್ತದೆ; 64-bit ಇದ್ದರೆ ಟೆರಾಬೈಟ್‌ಗಟ್ಟಲೆ RAM ಬೆಂಬಲಿಸುತ್ತದೆ).
🔥 ಪರೀಕ್ಷೆಗೆ ಉಳಿದಿದ್ದ ಹೆಚ್ಚುವರಿ ಮುಖ್ಯಾಂಶಗಳು & 3D ಫ್ಲಿಪ್ ಕಾರ್ಡ್ಸ್ Harvard vs Von Neumann, Pipelining, Clock Speed
ಪರಿಕಲ್ಪನೆ / ಪ್ರಶ್ನೆನಿಖರ ಉತ್ತರ / ವಿವರಣೆ
ಕಂಪ್ಯೂಟರ್ ವಿನ್ಯಾಸದ ಪಿತಾಮಹಜಾನ್ ವಾನ್ ನ್ಯೂಮನ್ (John Von Neumann - 1945) - ಸ್ಟೋರ್ಡ್ ಪ್ರೋಗ್ರಾಮ್ ಕಾನ್ಸೆಪ್ಟ್.
ವಾನ್ ನ್ಯೂಮನ್ ಬಾಟಲ್‌ನೆಕ್ (Bottleneck) ಎಂದರೇನು?ಡೇಟಾ ಮತ್ತು ಸೂಚನೆಗಳೆರಡೂ ಒಂದೇ ಬಸ್ ಮೂಲಕ ಚಲಿಸುವುದರಿಂದ CPU ಕಾಯಬೇಕಾದ ಸ್ಥಿತಿಯನ್ನು 'Von Neumann Bottleneck' ಎನ್ನುತ್ತಾರೆ.
ಹಾವರ್ಡ್ ವಿನ್ಯಾಸ (Harvard Architecture)ಡೇಟಾ ಮತ್ತು ಸೂಚನೆಗಳನ್ನು ಸಂಗ್ರಹಿಸಲು ಪ್ರತ್ಯೇಕ ಮೆಮೊರಿ ಮತ್ತು ಪ್ರತ್ಯೇಕ ಬಸ್‌ಗಳನ್ನು ಬಳಸುವ ವಿನ್ಯಾಸ (ಮೈಕ್ರೋಕಂಟ್ರೋಲರ್ ಮತ್ತು DSP ಗಳಲ್ಲಿ ಬಳಕೆ).
ಇನ್ಸ್‌ಟ್ರಕ್ಷನ್ ಪೈಪ್‌ಲೈನಿಂಗ್ (Pipelining)ಒಂದು ಸೂಚನೆ Execute ಆಗುತ್ತಿರುವಾಗಲೇ ಮುಂದಿನ ಸೂಚನೆಯನ್ನು Decode ಮತ್ತು Fetch ಮಾಡುವ ಮೂಲಕ CPU ವೇಗ ಹೆಚ್ಚಿಸುವ ತಂತ್ರಜ್ಞಾನ.
ಸಿಸ್ಟಮ್ ಕ್ಲಾಕ್ ವೇಗ (Clock Speed)CPU ನ ವೇಗವನ್ನು Hertz (MHz / GHz - Gigahertz) ಅಥವಾ MIPS (Million Instructions Per Second) ನಲ್ಲಿ ಅಳೆಯಲಾಗುತ್ತದೆ.
