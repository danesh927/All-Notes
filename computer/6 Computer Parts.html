ಗ್ಯಾಲರಿ 1: ಗಣಕಯಂತ್ರದ 12 ಪ್ರಮುಖ ಬಿಡಿಭಾಗಗಳು

🎨 ಗಣಕಯಂತ್ರದ 12 ಪ್ರಮುಖ ಭಾಗಗಳ ನೈಜ-ಶೈಲಿಯ HD ಅನಿಮೇಟೆಡ್ ಚಿತ್ರಗಳು ಮತ್ತು ಅವುಗಳ ಕಾರ್ಯ

ಮೊದಲು ಗಣಕಯಂತ್ರದ ಒಳಗಿರುವ 12 ಪ್ರಮುಖ ಹಾರ್ಡ್‌ವೇರ್ ಭಾಗಗಳು ನೋಡಲು ಹೇಗಿರುತ್ತವೆ, ಅವುಗಳ ಪಿನ್‌ಗಳ ರಚನೆ ಮತ್ತು ಅವುಗಳ ಮೂಲ ಕೆಲಸವೇನು ಎಂಬುದನ್ನು ಚಿತ್ರಗಳ ಸಮೇತ ತಿಳಿಯೋಣ:

1. CPU (ಮೈಕ್ರೋಪ್ರೊಸೆಸರ್)

1. ಸಿಪಿಯು ಚಿಪ್ (CPU / Microprocessor)

ಏನಿದು? ಮೇಲ್ಭಾಗದಲ್ಲಿ ಶಾಖ ಹರಡುವ ಲೋಹದ ಮುಚ್ಚಳ (IHS) ಮತ್ತು ಒಳಭಾಗದಲ್ಲಿ ಕೋಟ್ಯಂತರ ಟ್ರಾನ್ಸಿಸ್ಟರ್‌ಗಳಿರುವ ಸಿಲಿಕಾನ್ ಡೈ (ಗಣಕಯಂತ್ರದ ಮಿದುಳು).

ಕೆಲಸ: ಬಳಕೆದಾರ ನೀಡುವ ಎಲ್ಲಾ ಆದೇಶಗಳನ್ನು ಓದಿ, ಗಣಿತ ಮತ್ತು ತಾರ್ಕಿಕ ಲೆಕ್ಕಾಚಾರ ಮಾಡಿ ಫಲಿತಾಂಶ ನೀಡುತ್ತದೆ.

2. Motherboard (PCB)

2. ಮದರ್‌ಬೋರ್ಡ್ (Main System Board)

ಏನಿದು? CPU ಸಾಕೆಟ್, 4 DIMM RAM ಸ್ಲಾಟ್‌ಗಳು, PCIe ಸ್ಲಾಟ್, ಚಿಪ್‌ಸೆಟ್ ಮತ್ತು CMOS ಬ್ಯಾಟರಿ ಹೊಂದಿರುವ ಮುಖ್ಯ ಸರ್ಕ್ಯೂಟ್ ಬೋರ್ಡ್ (PCB).

ಕೆಲಸ: ಎಲ್ಲಾ ಬಿಡಿಭಾಗಗಳನ್ನು ಒಂದಕ್ಕೊಂದು ಬೆಸೆದು ವಿದ್ಯುತ್ ಮತ್ತು ಡೇಟಾ ಸಂಚಾರ ನಡೆಸುತ್ತದೆ.

3. RAM (ಪ್ರಾಥಮಿಕ ಮೆಮೊರಿ)

3. RAM ಕಾರ್ಡ್ (Volatile Memory)

ಏನಿದು? ಕಪ್ಪು ಬಣ್ಣದ DRAM ಚಿಪ್‌ಗಳು ಮತ್ತು ಕೆಳಭಾಗದಲ್ಲಿ ಮದರ್‌ಬೋರ್ಡ್ ಸ್ಲಾಟ್‌ಗೆ ಕೂರುವ ಚಿನ್ನದ ಕಾಂಟ್ಯಾಕ್ಟ್ ಪಿನ್‌ಗಳು (Notch ಸಹಿತ).

ಕೆಲಸ: ನಾವು ಪ್ರಸ್ತುತ ಓಪನ್ ಮಾಡಿರುವ ಆ್ಯಪ್ ಮತ್ತು ಫೈಲ್‌ಗಳನ್ನು CPU ಗೆ ತಕ್ಷಣ ಸಿಗುವಂತೆ ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ (ಪವರ್ ಹೋದರೆ ಅಳಿಸುತ್ತದೆ).

4. HDD (ಕಾಂತೀಯ ಶೇಖರಣೆ)

4. ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ಒಳರಚನೆ (HDD Platter)

ಏನಿದು? ತಿರುಗುವ ಕಾಂತೀಯ ತಟ್ಟೆ (Platter - 5400/7200 RPM), ಮಧ್ಯದ Spindle ಮತ್ತು ಚಲಿಸುವ Read/Write Actuator Arm.

ಕೆಲಸ: ಕಂಪ್ಯೂಟರ್ ಆಫ್ ಮಾಡಿದರೂ ನಮ್ಮ ವಿಂಡೋಸ್ OS, ಸಿನಿಮಾಗಳು, ಫೋಟೋಗಳು ಮತ್ತು ಫೈಲ್‌ಗಳನ್ನು ಶಾಶ್ವತವಾಗಿ ಕಾಪಾಡುತ್ತದೆ.

5. NVMe M.2 SSD

5. SSD (Solid State Drive - NVMe)

ಏನಿದು? ಯಾವುದೇ ಚಲಿಸುವ ಭಾಗಗಳಿಲ್ಲದೆ NAND Flash ಮೆಮೊರಿ ಚಿಪ್‌ಗಳನ್ನು ಹೊಂದಿರುವ ಆಧುನಿಕ ಶೇಖರಣಾ ಡ್ರೈವ್.

ಕೆಲಸ: ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌ಗಿಂತ 10 ಪಟ್ಟು ವೇಗವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸಿ ಕೇವಲ 5 ಸೆಕೆಂಡ್‌ಗಳಲ್ಲಿ ಕಂಪ್ಯೂಟರ್ ಆನ್ ಆಗುವಂತೆ ಮಾಡುತ್ತದೆ.

6. GPU (ಗ್ರಾಫಿಕ್ಸ್ ಕಾರ್ಡ್)

6. ಗ್ರಾಫಿಕ್ಸ್ ಕಾರ್ಡ್ (Dedicated GPU)

ಏನಿದು? ತನ್ನದೇ ಆದ ಪ್ರತ್ಯೇಕ ಮೆಮೊರಿ (VRAM) ಮತ್ತು ಕೂಲಿಂಗ್ ಫ್ಯಾನ್‌ಗಳನ್ನು ಹೊಂದಿರುವ ದೃಶ್ಯ ಸಂಸ್ಕರಣಾ ಕಾರ್ಡ್.

ಕೆಲಸ: 3D ಗ್ರಾಫಿಕ್ಸ್, ಗೇಮಿಂಗ್, ವಿಡಿಯೋ ರೆಂಡರಿಂಗ್ ಹಾಗೂ AI ಪ್ರೊಸೆಸಿಂಗ್ ಮಾಡಿ ಪರದೆಯ ಮೇಲೆ ಸ್ಪಷ್ಟ ಚಿತ್ರ ತೋರಿಸುತ್ತದೆ.

7. SMPS (ವಿದ್ಯುತ್ ಘಟಕ)

7. SMPS (Switched-Mode Power Supply)

ಏನಿದು? ಸಿಪಿಯು ಬಾಕ್ಸ್‌ನ ಹಿಂಭಾಗದಲ್ಲಿ ಫ್ಯಾನ್ ಸಹಿತ ಇರುವ ಲೋಹದ ವಿದ್ಯುತ್ ಪೂರೈಕೆ ಪೆಟ್ಟಿಗೆ.

ಕೆಲಸ: ಮನೆಯ 230V AC ವಿದ್ಯುತ್ ಅನ್ನು ಮದರ್‌ಬೋರ್ಡ್ ಮತ್ತು ಡ್ರೈವ್‌ಗಳಿಗೆ ಬೇಕಾದ +3.3V, +5V ಮತ್ತು +12V DC ವಿದ್ಯುತ್ ಆಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.

8. CMOS & BIOS Chip

8. CMOS ಬ್ಯಾಟರಿ ಮತ್ತು BIOS ROM ಚಿಪ್

ಏನಿದು? ಮದರ್‌ಬೋರ್ಡ್ ಮೇಲಿರುವ ರೂಪಾಯಿ ನಾಣ್ಯದ ಗಾತ್ರದ 3V ಬ್ಯಾಟರಿ ಮತ್ತು ROM ಚಿಪ್.

ಕೆಲಸ: ಕಂಪ್ಯೂಟರ್ ಆನ್ ಮಾಡಿದಾಗ ಬೂಟ್ ಮಾಡುವುದು BIOS ಕೆಲಸವಾದರೆ, ಆಫ್ ಆಗಿದ್ದಾಗಲೂ ಸಮಯ/ದಿನಾಂಕ ಕಾಪಾಡುವುದು CMOS ಬ್ಯಾಟರಿ ಕೆಲಸ.

9. NIC (LAN ನೆಟ್‌ವರ್ಕ್ ಕಾರ್ಡ್)

9. NIC ಕಾರ್ಡ್ (Network Interface Card)

ಏನಿದು? RJ-45 ಇಥರ್ನೆಟ್ ಕೇಬಲ್ ಮೂಲಕ ಕಂಪ್ಯೂಟರ್ ಅನ್ನು ಇಂಟರ್ನೆಟ್ ಅಥವಾ LAN ಗೆ ಜೋಡಿಸುವ ಕಾರ್ಡ್.

ಕೆಲಸ: ಪ್ರತಿ ಕಾರ್ಡ್‌‌ಗೂ ಜಗತ್ತಿನಲ್ಲಿ ಅನನ್ಯವಾದ 48-Bit (6 Byte) ಭೌತಿಕ ವಿಳಾಸ (MAC Address) ಶಾಶ್ವತವಾಗಿ ಮುದ್ರಿತವಾಗಿರುತ್ತದೆ.

10. Optical Disc (ಲೇಸರ್ ಡಿಸ್ಕ್)

10. ಆಪ್ಟಿಕಲ್ ಡಿಸ್ಕ್ (CD / DVD / Blu-Ray)

ಏನಿದು? ಬೆಳಕಿನ (Laser Beam) ತಂತ್ರಜ್ಞಾನದಿಂದ ಡೇಟಾ ಓದುವ ಪಾಲಿಕಾರ್ಬೊನೇಟ್ ಪ್ಲಾಸ್ಟಿಕ್ ಡಿಸ್ಕ್.

ಕೆಲಸ: ಡಿಸ್ಕ್ ಮೇಲ್ಮೈಯಲ್ಲಿ ಸಣ್ಣ ತಗ್ಗುಗಳು (Pits = 0) ಮತ್ತು ಸಮತಟ್ಟಾದ ಜಾಗಗಳನ್ನು (Lands = 1) ಮಾಡಿ ಡೇಟಾ ಸಂಗ್ರಹಿಸುತ್ತದೆ.

11. OMR, MICR & Barcode

11. ವಿಶೇಷ ಸ್ಕ್ಯಾನರ್‌ಗಳು (BCR, OMR, MICR)

ಏನಿದು? ಕಾಗದದ ಮೇಲಿನ ಗುರುತು ಮತ್ತು ಕೋಡ್‌ಗಳನ್ನು ನೇರವಾಗಿ ಕಂಪ್ಯೂಟರ್‌ಗೆ ಓದಿಕೊಡುವ ಇನ್‌ಪುಟ್ ಸಾಧನಗಳು.

ಕೆಲಸ: ಉತ್ಪನ್ನಗಳ ಬೆಲೆ ಓದಲು ಬಾರ್‌ಕೋಡ್ ರೀಡರ್, ಪರೀಕ್ಷೆಗಳ ಉತ್ತರ ಪತ್ರಿಕೆಗೆ OMR ಮತ್ತು ಬ್ಯಾಂಕ್ ಚೆಕ್‌ಗಳಿಗೆ MICR ಬಳಸುತ್ತಾರೆ.

12. Computer Ports

12. ಪ್ರಮುಖ ಕನೆಕ್ಟಿಂಗ್ ಪೋರ್ಟ್‌ಗಳು

ಏನಿದು? ಕಂಪ್ಯೂಟರ್‌ಗೆ ಹೊರಗಿನ ಸಾಧನಗಳನ್ನು (ಮಾನಿಟರ್, ಪ್ರಿಂಟರ್, ಪೆನ್‌ಡ್ರೈವ್) ಜೋಡಿಸುವ ಕಿಂಡಿಗಳು.

ಕೆಲಸ: VGA (15 ಪಿನ್ ನೀಲಿ), HDMI (19 ಪಿನ್ ಆಡಿಯೋ+ವಿಡಿಯೋ), USB 3.0 ಮತ್ತು RJ-45 (8 ಪಿನ್ LAN ಪೋರ್ಟ್).

ಭಾಗ 1: ಮೂಲಭೂತ ತತ್ವ ಮತ್ತು ಗಣಕಯಂತ್ರಗಳ ವರ್ಗೀಕರಣ

1. ಗಣಕಯಂತ್ರ ಎಂದರೇನು? ಅದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ? (IPOS Cycle, Von Neumann & Classification)

ಯಾವುದೇ ಗಣಕಯಂತ್ರದ ಒಳಭಾಗವನ್ನು ಓದುವ ಮುನ್ನ ಅದು ಯಾವ ಸಿದ್ಧಾಂತದ ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ ಎಂಬುದನ್ನು ಸರಳವಾಗಿ ಮತ್ತು ಅನಿಮೇಷನ್ ಮೂಲಕ ಅರ್ಥಮಾಡಿಕೊಳ್ಳೋಣ:

💡 ಸರಳ ಜೀವನದ ಉದಾಹರಣೆ (ಹಿಟ್ಟಿನ ಗಿರಣಿ / ಜ್ಯೂಸ್ ಮಷಿನ್ ಹೋಲಿಕೆ):
ನಾವು ಜ್ಯೂಸ್ ಮಾಡುವ ಮಿಕ್ಸಿಗೆ ಮಾವಿನ ಹಣ್ಣು ಹಾಕುತ್ತೇವೆ (ಇದು Input / ಕಚ್ಚಾ ಡೇಟಾ) ➔ ಮಿಕ್ಸಿ ತಿರುಗಿ ಅದನ್ನು ಅರೆಯುತ್ತದೆ (ಇದು Processing / ಸಂಸ್ಕರಣೆ) ➔ ನಮಗೆ ಕುಡಿಯಲು ಸಿದ್ಧವಾದ ಮಾವಿನ ಜ್ಯೂಸ್ ಸಿಗುತ್ತದೆ (ಇದು Output / ಮಾಹಿತಿ) ➔ ಉಳಿದ ಜ್ಯೂಸ್ ಅನ್ನು ಫ್ರಿಡ್ಜ್‌ನಲ್ಲಿ ಎತ್ತಿಡುತ್ತೇವೆ (ಇದು Storage / ಸಂಗ್ರಹಣೆ). ಕಂಪ್ಯೂಟರ್ ಕೂಡಾ ಇದೇ 4 ಹಂತಗಳಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ!

🎬 ಲೈವ್ ಅನಿಮೇಷನ್ 1: IPOS ಚಕ್ರ ಮತ್ತು ವಾನ್ ನ್ಯೂಮನ್ ಆರ್ಕಿಟೆಕ್ಚರ್ (Data ➔ Information Flow)

ಚಲಿಸುತ್ತಿರುವ ಚುಕ್ಕೆಗಳು ಹೇಗೆ ಕಚ್ಚಾ ಡೇಟಾ (Input) ಸಿಪಿಯು ಒಳಗೆ ಸಂಸ್ಕರಣೆಯಾಗಿ (Process), ಮೆಮೊರಿಯಲ್ಲಿ ಸೇವ್ ಆಗಿ (Storage), ಉಪಯುಕ್ತ ಮಾಹಿತಿಯಾಗಿ (Output) ಹೊರಬರುತ್ತದೆ ಎಂಬುದನ್ನು ತೋರಿಸುತ್ತಿವೆ.

🔄 1. IPOS ಚಕ್ರ (Input - Process - Output - Storage)

  • Data (ಡೇಟಾ / ದತ್ತಾಂಶ): ಕಂಪ್ಯೂಟರ್‌ಗೆ ನಾವು ನೀಡುವ ಅರ್ಥವಿಲ್ಲದ ಕಚ್ಚಾ ಅಂಕಿ-ಅಂಶಗಳು (Raw facts & figures). ಉದಾ: 95, ರಮೇಶ್, A+.
  • Processing (ಸಂಸ್ಕರಣೆ): ನೀಡಿದ ಕಚ್ಚಾ ಡೇಟಾವನ್ನು CPU ಸೂಚನೆಗಳ ಪ್ರಕಾರ ಜೋಡಿಸಿ ಲೆಕ್ಕ ಹಾಕುವ ಪ್ರಕ್ರಿಯೆ.
  • Information (ಮಾಹಿತಿ): ಸಂಸ್ಕರಣೆಯ ನಂತರ ನಮಗೆ ದೊರೆಯುವ ಅರ್ಥಪೂರ್ಣ ಫಲಿತಾಂಶ (Processed Data). ಉದಾ: "ರಮೇಶ್ ಪರೀಕ್ಷೆಯಲ್ಲಿ 95 ಅಂಕ ಪಡೆದು A+ ಶ್ರೇಣಿಯಲ್ಲಿ ಉತ್ತೀರ್ಣನಾಗಿದ್ದಾನೆ".
  • ಪರೀಕ್ಷಾ ಪ್ರಶ್ನೆ: "ಸಂಸ್ಕರಿಸಿದ ದತ್ತಾಂಶವನ್ನು (Processed Data) ಏನೆಂದು ಕರೆಯುತ್ತಾರೆ?" ➔ ಮಾಹಿತಿ (Information).

🏛️ 2. ವಾನ್ ನ್ಯೂಮನ್ ಆರ್ಕಿಟೆಕ್ಚರ್ (Von Neumann Architecture - 1945)

  • ಏನಿದು? ಇಂದು ನಾವು ಬಳಸುವ ಜಗತ್ತಿನ ಎಲ್ಲಾ ಕಂಪ್ಯೂಟರ್‌ಗಳ ಒಳವಿನ್ಯಾಸಕ್ಕೆ ಆಧಾರವಾಗಿರುವ ನೀಲನಕ್ಷೆ. ಇದನ್ನು ಗಣಿತಜ್ಞ ಜಾನ್ ವಾನ್ ನ್ಯೂಮನ್ (John von Neumann) 1945 ರಲ್ಲಿ ನೀಡಿದರು.
  • ಇದರ ಮುಖ್ಯ ತತ್ವವೇನು? ಇದನ್ನು "Stored-Program Concept" ಎನ್ನುತ್ತಾರೆ. ಅಂದರೆ ಕಂಪ್ಯೂಟರ್‌ಗೆ ನೀಡುವ ಡೇಟಾ (Data) ಮತ್ತು ಸೂಚನೆಗಳು (Instructions/Programs) ಎರಡನ್ನೂ ಒಂದೇ ಮೆಮೊರಿಯಲ್ಲಿ (RAM) ಬೈನರಿ ರೂಪದಲ್ಲಿ (0, 1) ಸಂಗ್ರಹಿಸಿಡಲಾಗುತ್ತದೆ.
  • ಪರೀಕ್ಷಾ ಪ್ರಶ್ನೆ: "Stored Program Concept ಪರಿಚಯಿಸಿದ ವಿಜ್ಞಾನಿ ಯಾರು?" ➔ ಜಾನ್ ವಾನ್ ನ್ಯೂಮನ್ (ಇದನ್ನು ಮೊದಲು ಬಳಸಿದ ಕಂಪ್ಯೂಟರ್: EDSAC).

🎨 ಗಣಕಯಂತ್ರಗಳ ವಿಧಗಳ ಲೈವ್ ಅನಿಮೇಟೆಡ್ ಚಿತ್ರಗಳು (Analog vs Digital vs Hybrid vs Supercomputer):

A. Analog Computer

1. ಅನಲಾಗ್ ಗಣಕಯಂತ್ರ (Analog Computer)

ನಿರಂತರವಾಗಿ ಬದಲಾಗುವ ಭೌತಿಕ ಪರಿಮಾಣಗಳನ್ನು (ತಾಪಮಾನ, ಒತ್ತಡ, ವೇಗ, ವೋಲ್ಟೇಜ್) ಅಳೆಯುವ ಯಂತ್ರಗಳು.
• ಉದಾಹರಣೆ: ವಾಹನದ ಸ್ಪೀಡೋಮೀಟರ್, ಪಾದರಸದ ಥರ್ಮಾಮೀಟರ್, ಭೂಕಂಪ ಮಾಪಕ (Seismograph), ವೋಲ್ಟ್‌ಮೀಟರ್.

B. Digital Computer

2. ಡಿಜಿಟಲ್ ಗಣಕಯಂತ್ರ (Digital Computer)

ದ್ವಿಮಾನ ಸಂಖ್ಯೆಗಳಾದ 0 ಮತ್ತು 1 (Binary Digits - Bits) ಆಧಾರದ ಮೇಲೆ ನಿಖರವಾಗಿ ಲೆಕ್ಕಾಚಾರ ಮಾಡುವ ಗಣಕಯಂತ್ರಗಳು.
• ಉದಾಹರಣೆ: ನಾವು ಬಳಸುವ Desktop PC, Laptop, Smartphone, Digital Watch, ಕ್ಯಾಲ್ಕುಲೇಟರ್.

C. Hybrid (ICU ECG Machine)

3. ಹೈಬ್ರಿಡ್ ಗಣಕಯಂತ್ರ (Hybrid Computer)

ಅನಲಾಗ್ ಮತ್ತು ಡಿಜಿಟಲ್ ಎರಡರ ಗುಣಲಕ್ಷಣಗಳನ್ನು ಒಳಗೊಂಡಿರುವ ವಿಶೇಷ ಗಣಕಯಂತ್ರಗಳು (ಅನಲಾಗ್ ಸಿಗ್ನಲ್ ಸ್ವೀಕರಿಸಿ ಡಿಜಿಟಲ್ ಸಂಖ್ಯೆ ತೋರಿಸುತ್ತವೆ).
• ಉದಾಹರಣೆ: ಆಸ್ಪತ್ರೆಗಳ ICU ನಲ್ಲಿರುವ ECG ಮಷಿನ್, ಪೆಟ್ರೋಲ್ ಬಂಕ್ ಮಷಿನ್, ರಾಡಾರ್ ವ್ಯವಸ್ಥೆ.

D. Supercomputer (PARAM)

4. ಸೂಪರ್ ಕಂಪ್ಯೂಟರ್ (Supercomputer)

ಸಾವಿರಾರು ಪ್ರೊಸೆಸರ್‌ಗಳನ್ನು ಹೊಂದಿರುವ ವಿಶ್ವದ ಅತಿ ವೇಗದ ಗಣಕಯಂತ್ರ. ವೇಗದ ಅಳತೆ: FLOPS. ಭಾರತದ ಮೊದಲ ಸೂಪರ್ ಕಂಪ್ಯೂಟರ್: PARAM 8000 (1991).

📏 ಗಾತ್ರ, ವೇಗ ಮತ್ತು ಕಾರ್ಯನಿರ್ವಹಣೆಯ ಆಧಾರದ ಮೇಲೆ ಸಂಪೂರ್ಣ ವರ್ಗೀಕರಣ ಕೋಷ್ಟಕ:

ಗಣಕಯಂತ್ರದ ವಿಧ ಅದು ಏನು ಮತ್ತು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ? (What & How it works) ಎಲ್ಲಿ ಬಳಸುತ್ತಾರೆ? ಮತ್ತು ಪರೀಕ್ಷಾ ಪ್ರಮುಖ ಅಂಶಗಳು
1. ಅನಲಾಗ್ ಕಂಪ್ಯೂಟರ್ (Analog Computer) ಇದು ಅಂಕಿಗಳನ್ನು (0, 1) ಎಣಿಸುವುದಿಲ್ಲ; ಬದಲಿಗೆ ಪ್ರಕೃತಿಯಲ್ಲಿ ನಿರಂತರವಾಗಿ ಬದಲಾಗುವ ಭೌತಿಕ ಪರಿಮಾಣಗಳನ್ನು (ಉದಾ: ಉಷ್ಣತೆ, ಒತ್ತಡ, ವಾಹನದ ವೇಗ, ವಿದ್ಯುತ್ ಪ್ರವಾಹ) ಮುಳ್ಳು ಅಥವಾ ಗ್ರಾಫ್ ಮೂಲಕ ಅಳೆಯುತ್ತದೆ. • ಬೈಕ್/ಕಾರಿನ ಸ್ಪೀಡೋಮೀಟರ್, ಪಾದರಸದ ಥರ್ಮಾಮೀಟರ್, ಭೂಕಂಪ ಅಳೆಯುವ ಸಿಸ್ಮೋಗ್ರಾಫ್ (Seismograph), ವೋಲ್ಟ್‌ಮೀಟರ್.
2. ಡಿಜಿಟಲ್ ಕಂಪ್ಯೂಟರ್ (Digital Computer) ಇದು ದ್ವಿಮಾನ ಸಂಖ್ಯೆಗಳಾದ 0 (OFF) ಮತ್ತು 1 (ON) [Binary Digits] ಆಧಾರದ ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಪ್ರತಿಯೊಂದು ಅಕ್ಷರ, ಫೋಟೋ ಮತ್ತು ಲೆಕ್ಕವನ್ನೂ 0 ಮತ್ತು 1 ಆಗಿ ಪರಿವರ್ತಿಸಿ ಶೇ.100 ರಷ್ಟು ನಿಖರ ಫಲಿತಾಂಶ ನೀಡುತ್ತದೆ. • ನಾವು ಬಳಸುವ Desktop PC, Laptop, Smartphone, Digital Watch, ಕ್ಯಾಲ್ಕುಲೇಟರ್.
3. ಹೈಬ್ರಿಡ್ ಕಂಪ್ಯೂಟರ್ (Hybrid Computer) ಇದು ಅನಲಾಗ್ ಮತ್ತು ಡಿಜಿಟಲ್ ಎರಡರ ಸಂಯೋಜನೆಯಾಗಿದೆ. ಇದರ ಒಳಗಿರುವ ಸೆನ್ಸಾರ್‌ಗಳು ರೋಗಿಯ ದೇಹದ ಬಡಿತ ಅಥವಾ ಉಷ್ಣತೆಯನ್ನು (ಅನಲಾಗ್ ರೂಪದಲ್ಲಿ) ಸ್ವೀಕರಿಸಿ, ಅದನ್ನು ಡಿಜಿಟಲ್ ಅಂಕಿಗಳಾಗಿ ಬದಲಿಸಿ ಪರದೆಯ ಮೇಲೆ ತೋರಿಸುತ್ತವೆ. • ಆಸ್ಪತ್ರೆಗಳ ICU ನಲ್ಲಿರುವ ECG ಯಂತ್ರ (ಹೃದಯ ಬಡಿತ ಅಳೆಯುವುದು), ವೆಂಟಿಲೇಟರ್, ಪೆಟ್ರೋಲ್ ಬಂಕ್‌ಗಳಲ್ಲಿ ಪೆಟ್ರೋಲ್ ಅಳೆದು ಬೆಲೆ ತೋರಿಸುವ ಯಂತ್ರ.
4. ಸೂಪರ್ ಕಂಪ್ಯೂಟರ್ (Supercomputer) ಜಗತ್ತಿನ ಅತ್ಯಂತ ವೇಗದ, ಅತ್ಯಂತ ದೊಡ್ಡ ಮತ್ತು ಅತ್ಯಂತ ದುಬಾರಿ ಗಣಕಯಂತ್ರ. ಸಾಮಾನ್ಯ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ 1 ಸಿಪಿಯು ಇದ್ದರೆ, ಸೂಪರ್ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಸಾವಿರಾರು ಸಿಪಿಯುಗಳು ಒಟ್ಟಿಗೆ (Parallel Processing) ಕೆಲಸ ಮಾಡುತ್ತವೆ. ಇದರ ವೇಗವನ್ನು FLOPS (Floating Point Operations Per Second - PetaFLOPS / ExaFLOPS) ನಲ್ಲಿ ಅಳೆಯುತ್ತಾರೆ. • ಹವಾಮಾನ ಮತ್ತು ಚಂಡಮಾರುತ ಮುನ್ಸೂಚನೆ, ಬಾಹ್ಯಾಕಾಶ ರಾಕೆಟ್ ಉಡಾವಣೆ (ISRO/NASA), ಪರಮಾಣು ಸಂಶೋಧನೆ.
• ವಿಶ್ವದ ಮೊದಲ ಸೂಪರ್ ಕಂಪ್ಯೂಟರ್: CDC 6600 (1964) / CRAY-1 (1976) (ಜನಕ: Seymour Cray).
• ಭಾರತದ ಮೊದಲ ಸೂಪರ್ ಕಂಪ್ಯೂಟರ್: PARAM 8000 (1991, C-DAC ಪುಣೆ) (ಜನಕ: ಡಾ. ವಿಜಯ್ ಭಟ್ಕರ್). ಇತ್ತೀಚಿನವು: AIRAWAT, PARAM Siddhi, Pratyush, Mihir.
5. ಮೇನ್‌ಫ್ರೇಮ್ ಕಂಪ್ಯೂಟರ್ (Mainframe) ಇದು ವೇಗಕ್ಕಿಂತ ಹೆಚ್ಚಾಗಿ ಏಕಕಾಲದಲ್ಲಿ ಸಾವಿರಾರು ಬಳಕೆದಾರರ (Multi-user) ಕೋಟ್ಯಂತರ ವಹಿವಾಟುಗಳನ್ನು (Bulk Data Processing / Transactions) ಒಂದು ಕ್ಷಣವೂ ನಿಲ್ಲದಂತೆ ನಿಭಾಯಿಸಲು ನಿರ್ಮಿಸಲಾದ ಬೃಹತ್ ಸರ್ವರ್ ಕಂಪ್ಯೂಟರ್. ವೇಗವನ್ನು MIPS ನಲ್ಲಿ ಅಳೆಯುತ್ತಾರೆ. • ಬ್ಯಾಂಕಿಂಗ್ ಕ್ಷೇತ್ರ (ದೇಶಾದ್ಯಂತ ಲಕ್ಷಾಂತರ ಜನ ಒಂದೇ ಸಮಯಕ್ಕೆ ATM/UPI ಬಳಸಿದರೂ ಹ್ಯಾಂಗ್ ಆಗದಂತೆ ನೋಡಿಕೊಳ್ಳಲು), ರೈಲ್ವೆ ಟಿಕೆಟ್ ರಿಸರ್ವೇಶನ್ (IRCTC), ವಿಮಾ ಕಂಪನಿಗಳು. ಉದಾ: IBM zSeries, HITAC.
6. ಮಿನಿ ಮತ್ತು ಮೈಕ್ರೋ ಕಂಪ್ಯೂಟರ್ • ಮಿನಿ ಕಂಪ್ಯೂಟರ್ (Mid-range): ಮೇನ್‌ಫ್ರೇಮ್‌ಗಿಂತ ಚಿಕ್ಕದು ಮತ್ತು ಮೈಕ್ರೋಕಂಪ್ಯೂಟರ್‌ಗಿಂತ ದೊಡ್ಡದು (10 ರಿಂದ 200 ಬಳಕೆದಾರರು ಏಕಕಾಲದಲ್ಲಿ ಬಳಸಬಹುದು).
• ಮೈಕ್ರೋ ಕಂಪ್ಯೂಟರ್ (Personal Computer): ಒಂದೇ ಒಂದು ಮೈಕ್ರೋಪ್ರೊಸೆಸರ್ ಚಿಪ್ ಹೊಂದಿರುವ, ಒಬ್ಬ ವ್ಯಕ್ತಿ (Single User) ಬಳಸುವ ಚಿಕ್ಕ ಕಂಪ್ಯೂಟರ್.		 • ಮಿನಿ ಕಂಪ್ಯೂಟರ್ ಉದಾಹರಣೆ: ವಿಶ್ವವಿದ್ಯಾಲಯ ಮತ್ತು ಕಾರ್ಖಾನೆಗಳಲ್ಲಿ ಬಳಸುವ PDP-8 (ಮೊದಲ ಮಿನಿ ಕಂಪ್ಯೂಟರ್), PDP-11, VAX.
• ಮೈಕ್ರೋ ಕಂಪ್ಯೂಟರ್ ಉದಾಹರಣೆ: Desktop PC, Laptop, Notebook, Tablet, Smartphone, PDA, Workstation (ವಿಡಿಯೋ ಎಡಿಟಿಂಗ್ ಮತ್ತು ಇಂಜಿನಿಯರಿಂಗ್ ವಿನ್ಯಾಸಕ್ಕೆ ಬಳಸುವ ಶಕ್ತಿಶಾಲಿ ಮೈಕ್ರೋಕಂಪ್ಯೂಟರ್ ಅನ್ನು Workstation ಎನ್ನುತ್ತಾರೆ).
ಭಾಗ 2: ಸಿಪಿಯು ಒಳರಚನೆ, ಲೈವ್ ಸಿಮ್ಯುಲೇಟರ್, ರೆಜಿಸ್ಟರ್‌ಗಳು ಮತ್ತು ಸಿಸ್ಟಮ್ ಬಸ್‌ಗಳು

2. ಸಿಪಿಯು (CPU) ಎಂದರೇನು? ಅದು ಒಂದು ಸೂಚನೆಯನ್ನು ಹೇಗೆ ಕಾರ್ಯಗತಗೊಳಿಸುತ್ತದೆ?

ಸಿಪಿಯು ಒಳಗಿನ ಪ್ರತಿಯೊಂದು ಭಾಗದ ಹೆಸರು, ಸರಳ ಹೋಲಿಕೆ, ಲೈವ್ ಸಿಮ್ಯುಲೇಟರ್ ಮತ್ತು ಪರೀಕ್ಷೆಯಲ್ಲಿ ಕೇಳುವ ಸೂಕ್ಷ್ಮ ವ್ಯತ್ಯಾಸಗಳು:

💡 ಸಿಪಿಯು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ? (ಅಡುಗೆ ಮನೆಯ ಸರಳ ಹೋಲಿಕೆ):
ಸಿಪಿಯು ಎಂಬುದು ಒಬ್ಬ ಮುಖ್ಯ ಬಾಣಸಿಗ (Master Chef) ಇದ್ದಂತೆ. ಬಾಣಸಿಗನ ಕೈಯಲ್ಲಿರುವ ಸೌಟು/ಮಸಾಲೆ ಡಬ್ಬಿಗಳೇ Registers (ತಕ್ಷಣ ಕೈಗೆ ಸಿಗುವವು). ಪಕ್ಕದ ಅಡುಗೆ ಕಟ್ಟೆಯೇ Cache Memory. ಅಡುಗೆ ಮನೆಯ ಕಪಾಟು RAM ಆದರೆ, ದೂರದ ಉಗ್ರಾಣವೇ (Store Room) Hard Disk. ಬಾಣಸಿಗನು ಉಗ್ರಾಣದಿಂದ ಸಾಮಗ್ರಿಗಳನ್ನು ಕಟ್ಟೆಯ ಮೇಲೆ ತಂದು ಅಡುಗೆ ಮಾಡುವಂತೆ, CPU ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌ನಿಂದ ಡೇಟಾವನ್ನು RAM ಮತ್ತು ರೆಜಿಸ್ಟರ್‌ಗೆ ತಂದು ಕೆಲಸ ಮಾಡುತ್ತದೆ!

🧠 A) ಸಿಪಿಯು ಒಳಗಿರುವ 3 ಪ್ರಮುಖ ವಿಭಾಗಗಳು (Internal Components of CPU):

1. ALU (Arithmetic Logic Unit - ಅಂಕಗಣಿತ ಮತ್ತು ತಾರ್ಕಿಕ ಘಟಕ)

ಏನಿದು? ಸಿಪಿಯು ಒಳಗೆ ನಿಜವಾದ ಲೆಕ್ಕಾಚಾರ ಮತ್ತು ಹೋಲಿಕೆ ನಡೆಯುವ ಸ್ಥಳ (ಕ್ಯಾಲ್ಕುಲೇಟರ್ ನಂತೆ).

ಇದರ 2 ಕೆಲಸಗಳೇನು?
• Arithmetic Section (ಅಂಕಗಣಿತ): ಕೂಡುವುದು (+), ಕಳೆಯುವುದು (-), ಗುಣಾಕಾರ (×) ಮತ್ತು ಭಾಗಾಕಾರ (÷) ಮಾಡುತ್ತದೆ.
• Logic Section (ತಾರ್ಕಿಕ ಹೋಲಿಕೆ): ಎರಡು ಮೌಲ್ಯಗಳನ್ನು ಹೋಲಿಸಿ ನಿರ್ಧಾರ ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ (ಯಾವುದು ದೊಡ್ಡದು $>$, ಯಾವುದು ಚಿಕ್ಕದು $<$, ಸಮವಾಗಿದೆಯೇ $=$, ಹಾಗೂ AND, OR, NOT, XOR ಗೇಟ್ ಕಾರ್ಯಾಚರಣೆಗಳು). ಉದಾ: "ಪಾಸ್‌ವರ್ಡ್ ಸರಿಯಾಗಿದೆಯೇ ಇಲ್ಲವೇ?" ಎಂದು ಚೆಕ್ ಮಾಡುವುದು ಇದೇ Logic Unit!
• ALU ಮಾಡುವ ಎಲ್ಲಾ ಲೆಕ್ಕಾಚಾರಗಳ ತಾತ್ಕಾಲಿಕ ಫಲಿತಾಂಶವು Accumulator (AC) ಎಂಬ ರೆಜಿಸ್ಟರ್‌ನಲ್ಲಿ ಸಂಗ್ರಹವಾಗುತ್ತದೆ.

2. CU (Control Unit - ನಿಯಂತ್ರಣ ಘಟಕ)

ಏನಿದು? ಕಂಪ್ಯೂಟರ್‌ನ "ಕೇಂದ್ರ ನರಮಂಡಲ" (Central Nervous System) ಅಥವಾ "ಟ್ರಾಫಿಕ್ ಪೊಲೀಸ್".

ಇದರ ಕೆಲಸವೇನು?
• ಮುಖ್ಯವಾದ ಅಂಶವೆಂದರೆ Control Unit ಸ್ವತಃ ಯಾವುದೇ ಡೇಟಾವನ್ನು ಪ್ರೊಸೆಸ್ ಮಾಡುವುದಿಲ್ಲ ಅಥವಾ ಲೆಕ್ಕ ಹಾಕುವುದಿಲ್ಲ!
• ಬದಲಿಗೆ ಇದು RAM ನಿಂದ ಸೂಚನೆಗಳನ್ನು ತಂದು (Fetch), ಅದನ್ನು ಅರ್ಥೈಸಿಕೊಂಡು (Decode), ALU, ಮೆಮೊರಿ ಮತ್ತು ಇನ್‌ಪುಟ್/ಔಟ್‌ಪುಟ್ ಸಾಧನಗಳಿಗೆ "ಈಗ ಯಾರು ಡೇಟಾ ಕಳುಹಿಸಬೇಕು, ಯಾರು ಸ್ವೀಕರಿಸಬೇಕು" ಎಂದು ಟೈಮಿಂಗ್ ಮತ್ತು ಕಂಟ್ರೋಲ್ ಸಿಗ್ನಲ್‌ಗಳನ್ನು ಕಳುಹಿಸಿ ಶಿಸ್ತು ಕಾಪಾಡುತ್ತದೆ.

3. Registers (ರೆಜಿಸ್ಟರ್‌ಗಳು - ಸಿಪಿಯು ಒಳಗಿನ ನೆನಪಿನ ಕೋಶಗಳು)

ಏನಿದು? ಸಿಪಿಯು ಚಿಪ್‌ನ ಒಳಭಾಗದಲ್ಲೇ ನಿರ್ಮಿಸಲಾದ ಅತ್ಯಂತ ಚಿಕ್ಕದಾದ (8-bit, 16-bit, 32-bit ಅಥವಾ 64-bit ಗಾತ್ರದ) ಮತ್ತು ಜಗತ್ತಿನಲ್ಲೇ ಅತ್ಯಂತ ವೇಗವಾದ ತಾತ್ಕಾಲಿಕ ಮೆಮೊರಿ.

ಇದರ ಕೆಲಸವೇನು?
• ALU ಲೆಕ್ಕ ಹಾಕುವಾಗ ಆ ಕ್ಷಣದಲ್ಲಿ ಬೇಕಾಗುವ ಸಂಖ್ಯೆಗಳನ್ನು ಮತ್ತು ತಕ್ಷಣದ ಉತ್ತರವನ್ನು ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ.
• Word Length (ವರ್ಡ್ ಲೆಂತ್): ಒಂದು ಸಿಪಿಯು ರೆಜಿಸ್ಟರ್ ಒಂದೇ ಬಾರಿಗೆ ಎಷ್ಟು ಬಿಟ್‌ಗಳನ್ನು ಪ್ರೊಸೆಸ್ ಮಾಡಬಲ್ಲದು ಎಂಬುದನ್ನು ಅದರ Word Size ಎನ್ನುತ್ತಾರೆ (ಆಧುನಿಕ ಸಿಪಿಯುಗಳು 64-Bit ಆಗಿವೆ).

🔄 B) Instruction Cycle (ಸಿಪಿಯು ಒಂದು ಕೆಲಸವನ್ನು ಮಾಡುವ 4 ಹಂತಗಳು - FDES Cycle & Live Simulator):

ನೀವು ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ 25 + 15 ಎಂದು ಟೈಪ್ ಮಾಡಿದಾಗ ಸಿಪಿಯು ಒಳಗೆ ಸೆಕೆಂಡಿನ ಕೋಟ್ಯಂತರ ಭಾಗದಲ್ಲಿ ಈ 4 ಹಂತಗಳ ಚಕ್ರ (Machine / Instruction Cycle) ನಡೆಯುತ್ತದೆ:
1. Fetch (ತರುವುದು): Control Unit (CU) ಪ್ರೋಗ್ರಾಮ್ ಕೌಂಟರ್ ಸಹಾಯದಿಂದ RAM ನಲ್ಲಿರುವ ಸೂಚನೆಯನ್ನು ಸಿಪಿಯು ಒಳಗಿನ Instruction Register (IR) ಗೆ ತರುತ್ತದೆ.
2. Decode (ಅರ್ಥೈಸುವುದು): ತಂದ ಸೂಚನೆಯು ಏನು ಹೇಳುತ್ತಿದೆ (ಕೂಡಬೇಕೇ ಅಥವಾ ಕಳೆಯಬೇಕೇ?) ಎಂದು Control Unit ಭಾಷಾಂತರಿಸಿ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುತ್ತದೆ.
3. Execute (ಕಾರ್ಯಗತಗೊಳಿಸುವುದು): ALU ಆ ಸೂಚನೆಯನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸಿ 25 + 15 = 40 ಎಂದು ಲೆಕ್ಕ ಹಾಕುತ್ತದೆ.
4. Store (ಸಂಗ್ರಹಿಸುವುದು): ಬಂದ ಉತ್ತರ 40 ಅನ್ನು ಮೊದಲು Accumulator ರೆಜಿಸ್ಟರ್‌ನಲ್ಲಿಟ್ಟು ನಂತರ RAM ಗೆ ಕಳುಹಿಸಿ ಪರದೆಯ ಮೇಲೆ ತೋರಿಸುತ್ತದೆ.
🎯 ಪರೀಕ್ಷಾ ಸೂತ್ರ: $\text{Instruction Cycle} = \text{Fetch Time (I-Time)} + \text{Execution Time (E-Time)}$

⚡ ಇಂಟರಾಕ್ಟಿವ್ CPU FDES ಚಕ್ರ (Fetch ➔ Decode ➔ Execute ➔ Store) ಮತ್ತು 3 ಸಿಸ್ಟಮ್ ಬಸ್‌ಗಳ ಲೈವ್ ಡಯಾಗ್ರಾಮ್

👆 ಮೇಲಿನ 1, 2, 3, 4 ಬಟನ್‌ಗಳನ್ನು ಒತ್ತಿ ಸಿಪಿಯು ಒಳಗೆ 25 + 15 = 40 ಲೆಕ್ಕಾಚಾರ ಹೇಗೆ ನಡೆಯುತ್ತದೆ ಎಂದು ಲೈವ್ ಆಗಿ ನೋಡಿ!

🔬 C) ಸಿಪಿಯು ಒಳಗಿನ 6 ವಿಶೇಷ ರೆಜಿಸ್ಟರ್‌ಗಳು (ಅವು ಏನು ಮತ್ತು ಏನು ಕೆಲಸ ಮಾಡುತ್ತವೆ?):

ರೆಜಿಸ್ಟರ್ ಹೆಸರು ಮತ್ತು ಪೂರ್ಣ ರೂಪ ಇದು ಏನು ಮತ್ತು ನಿಖರವಾಗಿ ಏನು ಕೆಲಸ ಮಾಡುತ್ತದೆ? ಪರೀಕ್ಷೆಯಲ್ಲಿ ಕೇಳುವ ಕೀವರ್ಡ್ (Exam Keyword)
1. PC
Program Counter		 ಇದನ್ನು Instruction Pointer (IP) ಎಂದೂ ಕರೆಯುತ್ತಾರೆ. ಪ್ರಸ್ತುತ ಒಂದು ಸೂಚನೆ ನಡೆಯುತ್ತಿರುವಾಗಲೇ, ಸಿಪಿಯು ಇದರ ನಂತರ ಮುಂದೆ ಯಾವ ಸೂಚನೆಯನ್ನು (Next Instruction) ಕಾರ್ಯಗತಗೊಳಿಸಬೇಕು ಎಂಬುದರ ಮೆಮೊರಿ ವಿಳಾಸವನ್ನು (Address) ಗುರುತು ಹಿಡಿದುಕೊಂಡು ಕಾಯುತ್ತಿರುತ್ತದೆ. "Holds the address of the NEXT instruction to be executed"
2. IR
Instruction Register		 RAM ನಿಂದ ಸಿಪಿಯು ಒಳಗೆ ತರಲಾದ ಮತ್ತು ಪ್ರಸ್ತುತ ಈ ಕ್ಷಣದಲ್ಲಿ ಡಿಕೋಡ್ ಆಗಿ ಕಾರ್ಯಗತಗೊಳ್ಳುತ್ತಿರುವ (Currently executing) ಸೂಚನೆಯನ್ನು ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುವ ರೆಜಿಸ್ಟರ್. "Holds the CURRENT instruction being decoded/executed"
3. MAR
Memory Address Register		 ಸಿಪಿಯು RAM ನಿಂದ ಡೇಟಾ ಓದಬೇಕಾದರೆ ಅಥವಾ RAM ಗೆ ಡೇಟಾ ಬರೆಯಬೇಕಾದರೆ, RAM ನ ಯಾವ ಕೋಣೆಯ (ವಿಳಾಸದ) ಜೊತೆ ಸಂಪರ್ಕ ಸಾಧಿಸಬೇಕು ಎಂಬ ಆ ಸಕ್ರಿಯ ವಿಳಾಸವನ್ನು ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ. ಇದು ನೇರವಾಗಿ Address Bus ಗೆ ಜೋಡಣೆಯಾಗಿರುತ್ತದೆ. "Holds the active memory location address to read/write"
4. MDR / MBR
Memory Data / Buffer Register		 MAR ವಿಳಾಸ ತೋರಿಸಿದರೆ, ಆ ವಿಳಾಸದಿಂದ ಸಿಪಿಯುಗೆ ಬಂದಿರುವ ಅಥವಾ ಸಿಪಿಯುನಿಂದ ಆ ವಿಳಾಸಕ್ಕೆ ಹೋಗುತ್ತಿರುವ ನಿಜವಾದ ಡೇಟಾ/ಮೌಲ್ಯವನ್ನು (Actual Data) ತಾತ್ಕಾಲಿಕವಾಗಿ ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುವ ರೆಜಿಸ್ಟರ್. ಇದು ನೇರವಾಗಿ Data Bus ಗೆ ಜೋಡಣೆಯಾಗಿರುತ್ತದೆ. "Holds the actual data being transferred to/from memory"
5. AC
Accumulator		 ALU ಯಾವುದೇ ಗಣಿತ ಅಥವಾ ತಾರ್ಕಿಕ ಲೆಕ್ಕಾಚಾರ ಮಾಡಿದಾಗ (ಉದಾ: $25 + 15 = 40$), ಆ ತಕ್ಷಣದ ಮಧ್ಯಂತರ ಮತ್ತು ಅಂತಿಮ ಫಲಿತಾಂಶವನ್ನು (Intermediate & Final ALU Result) ಸಂಗ್ರಹಿಸಿಟ್ಟುಕೊಳ್ಳುವ ಮುಖ್ಯ ರೆಜಿಸ್ಟರ್. "Stores immediate results of ALU operations"
6. SP & Status
Stack Pointer & Flag Register		 • Stack Pointer (SP): ಮೆಮೊರಿಯಲ್ಲಿರುವ Stack (LIFO - Last In First Out) ನ ಮೇಲ್ಭಾಗದ ವಿಳಾಸ ತೋರಿಸುತ್ತದೆ.
• Flag / Status Register (PSW): ಲೆಕ್ಕಾಚಾರದ ವೇಳೆ ಉತ್ತರ ಸೊನ್ನೆಯಾದರೆ (Zero Flag), ಮೈನಸ್ ಆದರೆ (Sign Flag) ಅಥವಾ ಮಿತಿ ಮೀರಿದರೆ (Overflow/Carry Flag) ಸೂಚನೆ ನೀಡುತ್ತದೆ.		 "Tracks Top of Stack (SP) & CPU condition flags"

🛤️ D) ಸಿಸ್ಟಮ್ ಬಸ್‌ಗಳು (System Buses) ಮತ್ತು ಸಿಪಿಯು ವೇಗದ ಪದಗಳು (CISC vs RISC, Multi-Core):

🚌 System Bus ಎಂದರೇನು? (3 ವಿಧದ ಬಸ್‌ಗಳು)

ಏನಿದು? ಮದರ್‌ಬೋರ್ಡ್ ಮೇಲೆ ಒಂದು ಭಾಗದಿಂದ ಇನ್ನೊಂದು ಭಾಗಕ್ಕೆ ವಿದ್ಯುತ್ ಸಂಕೇತಗಳ (0, 1) ರೂಪದಲ್ಲಿ ಡೇಟಾ ಸಾಗಿಸುವ ತಾಮ್ರದ ಸೂಕ್ಷ್ಮ ಎಳೆಗಳ ರಸ್ತೆ (ಹೆದ್ದಾರಿ).

  • 1. Address Bus (ವಿಳಾಸ ಬಸ್ - ಏಕಮುಖ / Unidirectional): ಇದು ಕೇವಲ CPU ನಿಂದ ಹೊರಟು RAM ಅಥವಾ I/O ಸಾಧನಗಳ ಕಡೆಗೆ ಮಾತ್ರ ಚಲಿಸುತ್ತದೆ (ಎಲ್ಲಿ ಡೇಟಾ ಇದೆ ಎಂದು ವಿಳಾಸ ಹೇಳಲು).
    🎯 ಪರೀಕ್ಷಾ ರಹಸ್ಯ: ಒಂದು ಕಂಪ್ಯೂಟರ್‌ಗೆ ಗರಿಷ್ಠ ಎಷ್ಟು GB RAM ಹಾಕಬಹುದು ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸುವುದು ಇದೇ Address Bus! (ಉದಾ: 32-Bit Address Bus ಇದ್ದರೆ $2^{32} = \mathbf{4\text{ GB RAM}}$ ಮಾತ್ರ ಗುರುತಿಸುತ್ತದೆ).
  • 2. Data Bus (ಡೇಟಾ ಬಸ್ - ದ್ವಿಮುಖ / Bidirectional): ಇದು CPU ನಿಂದ ಮೆಮೊರಿಗೆ ಮತ್ತು ಮೆಮೊರಿಯಿಂದ CPU ಗೆ ಎರಡೂ ದಿಕ್ಕಿನಲ್ಲಿ ನಿಜವಾದ ಡೇಟಾ ಸಾಗಿಸುತ್ತದೆ. ಇದರ ಅಗಲವು (32-bit / 64-bit) ಕಂಪ್ಯೂಟರ್ ವೇಗವನ್ನು ನಿರ್ಧರಿಸುತ್ತದೆ.
  • 3. Control Bus (ನಿಯಂತ್ರಣ ಬಸ್): ಸಿಪಿಯುನ Control Unit ಕಳುಹಿಸುವ Memory Read, Memory Write, Interrupt (IRQ) ಆಜ್ಞೆಗಳನ್ನು ಸಾಗಿಸುತ್ತದೆ.

⚡ ಸಿಪಿಯುಗೆ ಸಂಬಂಧಿಸಿದ ಪ್ರಮುಖ ಪರೀಕ್ಷಾ ಪದಗಳು

  • Clock Speed (ಕ್ಲಾಕ್ ಸ್ಪೀಡ್): ಸಿಪಿಯು ಪ್ರತಿ ಸೆಕೆಂಡಿಗೆ ಎಷ್ಟು ಚಕ್ರಗಳ (Cycles) ಕೆಲಸ ಮಾಡುತ್ತದೆ ಎಂಬ ವೇಗ. ಇದನ್ನು Hertz (MHz / GHz) ನಲ್ಲಿ ಅಳೆಯುತ್ತಾರೆ. ($1\text{ GHz} = \text{ಪ್ರತಿ ಸೆಕೆಂಡಿಗೆ } 10^9 \text{ (100 ಕೋಟಿ) ಕಂಪನಗಳು}$).
  • Multi-Core Processor: ಒಂದೇ ಸಿಪಿಯು ಚಿಪ್ ಒಳಗೆ ಎರಡು ಅಥವಾ ಹೆಚ್ಚಿನ ಸ್ವತಂತ್ರ ಸಿಪಿಯುಗಳನ್ನು ಅಳವಡಿಸುವುದು. (Dual-Core = 2, Quad-Core = 4, Hexa-Core = 6, Octa-Core = 8, Deca-Core = 10 Cores).
  • Hyper-Threading (ಹೈಪರ್ ಥ್ರೆಡ್ಡಿಂಗ್): ಒಂದು ಭೌತಿಕ ಸಿಪಿಯು ಕೋರ್ ಅನ್ನು ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್‌ಗೆ ಎರಡು ವರ್ಚುವಲ್ ಕೋರ್‌ಗಳಂತೆ (Logical Threads) ಕಾಣುವಂತೆ ಮಾಡಿ ಏಕಕಾಲದಲ್ಲಿ ಎರಡು ಕೆಲಸ ಮಾಡಿಸುವ ತಂತ್ರಜ್ಞಾನ.
  • CISC vs RISC ಆರ್ಕಿಟೆಕ್ಚರ್:
    • CISC (Complex Instruction Set Computer): ಸಂಕೀರ್ಣ ಸೂಚನೆಗಳನ್ನು ಹೊಂದಿರುವ ಡೆಸ್ಕ್‌ಟಾಪ್/ಲ್ಯಾಪ್‌ಟಾಪ್ ಪ್ರೊಸೆಸರ್‌ಗಳು (ಉದಾ: Intel Core, AMD Ryzen).
    • RISC (Reduced Instruction Set Computer): ಸರಳ ಮತ್ತು ಕಡಿಮೆ ವಿದ್ಯುತ್ ಬಳಸುವ ಸ್ಮಾರ್ಟ್‌ಫೋನ್ ಹಾಗೂ ಆ್ಯಪಲ್ ಪ್ರೊಸೆಸರ್‌ಗಳು (ಉದಾ: ARM, Snapdragon, Apple M1/M2/M3).
ಭಾಗ 3: ಮದರ್‌ಬೋರ್ಡ್ ಪ್ರತಿಯೊಂದು ಭಾಗ ಮತ್ತು ಬೂಟಿಂಗ್ ಪ್ರಕ್ರಿಯೆ

3. ಇಂಟರಾಕ್ಟಿವ್ ಮದರ್‌ಬೋರ್ಡ್ (Motherboard) ಮತ್ತು ಸಂಪೂರ್ಣ ಬೂಟಿಂಗ್ ಪ್ರಕ್ರಿಯೆ

ಮೊದಲು ಕೆಳಗಿನ ಇಂಟರಾಕ್ಟಿವ್ ಬೋರ್ಡ್ ಮೇಲಿರುವ ಭಾಗಗಳನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ ನೋಡಿ, ನಂತರ ಕೆಳಗಿರುವ ವಿವರಣೆ ಮತ್ತು ಲೈವ್ ಬೂಟಿಂಗ್ ಅನಿಮೇಷನ್ ಓದಿ:

👆 ಮಾಹಿತಿ ನೋಡಲು ಚಿತ್ರದ ಮೇಲಿರುವ ಯಾವುದೇ ಭಾಗದ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ

📌 ಮದರ್‌ಬೋರ್ಡ್ ಎಂದರೇನು? (PCB & Form Factor)

ಮದರ್‌ಬೋರ್ಡ್ ಅನ್ನು Mainboard, System Board ಅಥವಾ Logic Board (Apple ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ) ಎಂದೂ ಕರೆಯುತ್ತಾರೆ. ಇದು ಫೈಬರ್‌ಗ್ಲಾಸ್ ಮತ್ತು ತಾಮ್ರದ ಪದರಗಳಿಂದ ಮಾಡಲ್ಪಟ್ಟ PCB (Printed Circuit Board) ಆಗಿದೆ.

ಮದರ್‌ಬೋರ್ಡ್‌ನ ಪ್ರಮಾಣಿತ ಅಳತೆಯನ್ನು (ಗಾತ್ರವನ್ನು) Form Factor ಎನ್ನುತ್ತಾರೆ. ಪ್ರಮುಖ ವಿಧಗಳು: ATX (Advanced Technology Extended - 1995 ರಲ್ಲಿ Intel ಪರಿಚಯಿಸಿತು), Micro-ATX ಮತ್ತು Mini-ITX.

🔍 A) ಮದರ್‌ಬೋರ್ಡ್ ಮೇಲಿರುವ ಪ್ರತಿಯೊಂದು ಪ್ರಮುಖ ಭಾಗದ ಸಂಪೂರ್ಣ ವಿವರಣೆ:

1. Chipset: Northbridge vs Southbridge

ಏನಿದು? ಮದರ್‌ಬೋರ್ಡ್ ಮೇಲೆ ಡೇಟಾ ಸಂಚಾರವನ್ನು ನಿಯಂತ್ರಿಸುವ ಎರಡು ಪ್ರಮುಖ ಸಹಾಯಕ ಚಿಪ್‌ಗಳು:

  • Northbridge (ನಾರ್ತ್‌ಬ್ರಿಡ್ಜ್ - ವೇಗದ ಸೇತುವೆ): ಇದು ಸಿಪಿಯು ಸಾಕೆಟ್‌ಗೆ ಹತ್ತಿರದಲ್ಲಿರುತ್ತದೆ. ಇದು ಕಂಪ್ಯೂಟರ್‌ನ ಅತಿ ವೇಗದ ಭಾಗಗಳಾದ CPU, RAM ಮತ್ತು Graphics Card (PCIe/AGP) ನಡುವೆ ನೇರ ಸಂಪರ್ಕ ಕಲ್ಪಿಸುತ್ತದೆ. (ಇದನ್ನು Memory Controller Hub ಎನ್ನುತ್ತಾರೆ).
  • Southbridge (ಸೌತ್‌ಬ್ರಿಡ್ಜ್ - ನಿಧಾನಗತಿಯ ಸೇತುವೆ): ಇದು ಸಿಪಿಯುನಿಂದ ದೂರವಿರುತ್ತದೆ. ಕಂಪ್ಯೂಟರ್‌ನ ನಿಧಾನಗತಿಯ ಸಾಧನಗಳಾದ USB ಪೋರ್ಟ್‌ಗಳು, Hard Disk (SATA), BIOS ROM, Audio, ಕೀಬೋರ್ಡ್ ಮತ್ತು ಮೌಸ್ಗಳನ್ನು ನಿಯಂತ್ರಿಸುತ್ತದೆ. (ಇದನ್ನು I/O Controller Hub ಎನ್ನುತ್ತಾರೆ).

2. BIOS, UEFI ಮತ್ತು CMOS ನಡುವಿನ ನಿಖರ ವ್ಯತ್ಯಾಸ

ವಿದ್ಯಾರ್ಥಿಗಳು ಪರೀಕ್ಷೆಯಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಗೊಂದಲ ಮಾಡಿಕೊಳ್ಳುವ ಮೂರು ಪದಗಳಿವು:

  • BIOS (Basic Input Output System): ಇದು ಮದರ್‌ಬೋರ್ಡ್ ಮೇಲಿನ ROM ಚಿಪ್ ಒಳಗೆ ಶಾಶ್ವತವಾಗಿ ಬರೆಯಲಾದ ತಂತ್ರಾಂಶ (Firmware). ಕಂಪ್ಯೂಟರ್ ಆನ್ ಮಾಡಿದ ತಕ್ಷಣ ಎಲ್ಲಾ ಭಾಗಗಳನ್ನು ಪರೀಕ್ಷಿಸಿ ಬೂಟ್ ಮಾಡುವುದು ಇದರ ಕೆಲಸ.
  • UEFI (Unified Extensible Firmware Interface): ಹಳೆಯ ನೀಲಿ ಪರದೆಯ BIOS ಬದಲಿಗೆ ಇಂದಿನ ಹೊಸ ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ ಬಂದಿರುವ ಆಧುನಿಕ ಫರ್ಮ್‌ವೇರ್. ಇದರಲ್ಲಿ ಮೌಸ್ ಬಳಸಬಹುದು, 2 TB ಗಿಂತ ದೊಡ್ಡ ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ಬೆಂಬಲಿಸುತ್ತದೆ ಮತ್ತು Secure Boot ಸುರಕ್ಷತೆ ಇರುತ್ತದೆ.
  • CMOS (Complementary Metal-Oxide Semiconductor): BIOS ನಲ್ಲಿ ನಾವು ಮಾಡುವ ಸೆಟ್ಟಿಂಗ್ಸ್ ಹಾಗೂ ಸಿಸ್ಟಮ್ ದಿನಾಂಕ ಮತ್ತು ಸಮಯವನ್ನು (RTC - Real Time Clock) ನೆನಪಿಟ್ಟುಕೊಳ್ಳುವ ಚಿಕ್ಕ ಚಿಪ್. ಇದಕ್ಕೆ CR2032 (3V Lithium Coin Battery) ನಿರಂತರ ವಿದ್ಯುತ್ ನೀಡುತ್ತದೆ.

🚀 B) ಕಂಪ್ಯೂಟರ್ ಆನ್ ಮಾಡಿದಾಗ ಏನಾಗುತ್ತದೆ? (Booting Process ಲೈವ್ ಅನಿಮೇಷನ್ ಮತ್ತು 5 ಹಂತಗಳು):

🚀 ಲೈವ್ ಅನಿಮೇಷನ್ 3: ಕಂಪ್ಯೂಟರ್ ಆನ್ ಮಾಡಿದಾಗ ನಡೆಯುವ 5 ಬೂಟಿಂಗ್ ಹಂತಗಳು (Booting Sequence)

Booting (ಬೂಟಿಂಗ್) ಎಂದರೇನು? ಕಂಪ್ಯೂಟರ್‌ನ ಪವರ್ ಬಟನ್ ಒತ್ತಿದ ಕ್ಷಣದಿಂದ ಹಿಡಿದು, ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌‌ನಲ್ಲಿ ಮಲಗಿರುವ ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ (Windows / Linux) ಅನ್ನು ಎಬ್ಬಿಸಿ RAM ಮೆಮೊರಿಗೆ ಲೋಡ್ ಮಾಡಿ, ನಮ್ಮ ಮುಂದೆ Desktop ಪರದೆ ಬರುವವರೆಗಿನ ಸಂಪೂರ್ಣ ಪ್ರಕ್ರಿಯೆಯನ್ನು Booting ಎನ್ನುತ್ತಾರೆ.

ಬೂಟಿಂಗ್ ನಡೆಯುವ 5 ನಿಖರ ಹಂತಗಳು (ಪರೀಕ್ಷಾ ಕ್ರಮ):
ಹಂತ 1 (Power Supply): ನೀವು ಪವರ್ ಬಟನ್ ಒತ್ತಿದ ತಕ್ಷಣ SMPS ಮದರ್‌ಬೋರ್ಡ್ ಮತ್ತು ಸಿಪಿಯುಗೆ DC ವಿದ್ಯುತ್ ಹರಿಸುತ್ತದೆ.
ಹಂತ 2 (BIOS / UEFI ಸಕ್ರಿಯ): ಸಿಪಿಯು ನೇರವಾಗಿ ROM ಚಿಪ್‌ನಲ್ಲಿರುವ BIOS ಪ್ರೋಗ್ರಾಮ್ ಅನ್ನು ಓದಲು ಪ್ರಾರಂಭಿಸುತ್ತದೆ.
ಹಂತ 3 (POST - Power-On Self-Test): BIOS ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ RAM, ಕೀಬೋರ್ಡ್, ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ಸರಿಯಾಗಿ ಜೋಡಣೆಯಾಗಿವೆಯೇ ಎಂದು ಸ್ವಯಂ-ಪರೀಕ್ಷೆ (POST) ನಡೆಸುತ್ತದೆ. ಒಂದು ವೇಳೆ RAM ಇಲ್ಲದಿದ್ದರೆ ಅಥವಾ ಕೆಟ್ಟಿದ್ದರೆ ಮದರ್‌ಬೋರ್ಡ್ "Beep... Beep..." ಶಬ್ದ (Beep Codes) ಮಾಡಿ ನಿಲ್ಲುತ್ತದೆ.
ಹಂತ 4 (MBR / Bootstrap Loader): POST ಯಶಸ್ವಿಯಾದ ನಂತರ, BIOS ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ಅಥವಾ SSD ಯ ಮೊದಲ ಸೆಕ್ಟರ್ (Sector 0) ನಲ್ಲಿರುವ MBR (Master Boot Record) / GPT ಯನ್ನು ಹುಡುಕುತ್ತದೆ. ಅಲ್ಲಿರುವ Bootstrap Loader ಎಂಬ ಸಣ್ಣ ಪ್ರೋಗ್ರಾಮ್ ಅನ್ನು ಓದುತ್ತದೆ.
ಹಂತ 5 (OS Kernel Loading): ಬೂಟ್ ಲೋಡರ್ ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌ನಲ್ಲಿರುವ ಮುಖ್ಯ ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ (OS Kernel) ಅನ್ನು RAM ಒಳಗೆ ಲೋಡ್ ಮಾಡುತ್ತದೆ. ಈಗ ಕಂಪ್ಯೂಟರ್ ನಮ್ಮ ಬಳಕೆಗೆ ಸಿದ್ಧವಾಗುತ್ತದೆ!

🔥 ಬೂಟಿಂಗ್‌ನ 2 ವಿಧಗಳು (ಪರೀಕ್ಷೆಯಲ್ಲಿ ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆ):
• 1. Cold Booting (ಕೋಲ್ಡ್ ಬೂಟಿಂಗ್ / Hard Boot): ಸಂಪೂರ್ಣವಾಗಿ ಆಫ್ ಆಗಿರುವ (Shut down ಆಗಿರುವ) ಕಂಪ್ಯೂಟರ್ ಅನ್ನು ಪವರ್ ಬಟನ್ ಒತ್ತಿ ಹೊಸದಾಗಿ ಆನ್ ಮಾಡುವುದು.
• 2. Warm Booting (ವಾರ್ಮ್ ಬೂಟಿಂಗ್ / Soft Boot): ಈಗಾಗಲೇ ಆನ್ ಆಗಿ ಕೆಲಸ ಮಾಡುತ್ತಿರುವ ಕಂಪ್ಯೂಟರ್ ಅನ್ನು ಪವರ್ ಆಫ್ ಮಾಡದೆ Restart / Reboot ಮಾಡುವುದು (ಶಾರ್ಟ್‌ಕಟ್ ಕೀ: Ctrl + Alt + Delete).
ಭಾಗ 4: ಗಣಕಯಂತ್ರದ ಮೆಮೊರಿ ವ್ಯವಸ್ಥೆ (ಸಂಪೂರ್ಣ ಪಠ್ಯ + ಲೈವ್ ಅನಿಮೇಷನ್)

4. ಕ್ಯಾಶ್ (Cache L1, L2, L3), RAM (SRAM vs DRAM), ROM ವಿಧಗಳು ಮತ್ತು ವರ್ಚುವಲ್ ಮೆಮೊರಿ

ಮೆಮೊರಿಗಳ ವೇಗದ ಕ್ರಮ, ಪ್ರತಿಯೊಂದು ಮೆಮೊರಿಯ ಒಳರಚನೆ, ಲೈವ್ ಅನಿಮೇಷನ್ ಮತ್ತು ಪರೀಕ್ಷಾ ಹೋಲಿಕೆಗಳು:

💡 ಪರೀಕ್ಷಾ ಸೂತ್ರ - ಮೆಮೊರಿ ಪಿರಮಿಡ್ (Memory Hierarchy):
ನಾವು ಸಿಪಿಯು ಕಡೆಯಿಂದ ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ಕಡೆಗೆ ಹೋದಂತೆ: ವೇಗ (Speed) ಮತ್ತು ಬೆಲೆ (Cost per bit) ಕಡಿಮೆಯಾಗುತ್ತಾ ಹೋಗುತ್ತದೆ, ಆದರೆ ಸಂಗ್ರಹಣಾ ಸಾಮರ್ಥ್ಯ (Storage Capacity) ಹೆಚ್ಚಾಗುತ್ತಾ ಹೋಗುತ್ತದೆ!
🚀 ವೇಗದ ಕ್ರಮ (ಅತ್ಯಂತ ವೇಗದಿಂದ ನಿಧಾನಕ್ಕೆ):
1. CPU Registers ➔ 2. L1 Cache ➔ 3. L2 Cache ➔ 4. L3 Cache ➔ 5. Main RAM (DRAM) ➔ 6. SSD (NVMe/SATA) ➔ 7. Hard Disk (HDD) ➔ 8. Optical Disc / Magnetic Tape

⛰️ ಲೈವ್ ಅನಿಮೇಷನ್ 4: ಮೆಮೊರಿ ಪಿರಮಿಡ್ (Memory Hierarchy) ಮತ್ತು SRAM vs DRAM ಕಾರ್ಯನಿರ್ವಹಣೆ

⚡ A) Cache Memory (ಕ್ಯಾಶ್ ಮೆಮೊರಿ ಎಂದರೇನು? ಅದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ?):

ಕ್ಯಾಶ್ ಮೆಮೊರಿ ಏಕೆ ಬೇಕು? (Cache Hit vs Cache Miss)

ಸಮಸ್ಯೆ: ಸಿಪಿಯು ಪ್ರಚಂಡ ವೇಗದಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಆದರೆ ಮುಖ್ಯ ಮೆಮೊರಿಯಾದ RAM ಸಿಪಿಯುಗಿಂತ ನಿಧಾನವಾಗಿರುತ್ತದೆ. ಸಿಪಿಯು ಪ್ರತಿ ಬಾರಿ RAM ನಿಂದ ಡೇಟಾ ತರಲು ಕಾಯುತ್ತಾ ಕುಳಿತರೆ ಸಮಯ ವ್ಯರ್ಥವಾಗುತ್ತದೆ.

ಪರಿಹಾರ (ಕೆಲಸ): ಇದಕ್ಕಾಗಿ CPU ಮತ್ತು RAM ನಡುವೆ ಅತಿ ವೇಗದ SRAM ನಿಂದ ಮಾಡಲ್ಪಟ್ಟ Cache Memory ಇಡಲಾಗುತ್ತದೆ. ಸಿಪಿಯುಗೆ ಪದೇ ಪದೇ ಬೇಕಾಗುವ ಡೇಟಾವನ್ನು ಕ್ಯಾಶ್ ತನ್ನಲ್ಲಿ ಇಟ್ಟುಕೊಂಡು ತಕ್ಷಣ ನೀಡುತ್ತದೆ.

  • Cache Hit: ಸಿಪಿಯು ಹುಡುಕಿದ ಡೇಟಾ ಕ್ಯಾಶ್ ಒಳಗೇ ಸಿಕ್ಕರೆ ಅದನ್ನು Cache Hit ಎನ್ನುತ್ತಾರೆ.
  • Cache Miss: ಕ್ಯಾಶ್‌ನಲ್ಲಿ ಸಿಗದೆ RAM ಗೆ ಹೋಗಿ ತರಬೇಕಾದರೆ ಅದನ್ನು Cache Miss ಎನ್ನುತ್ತಾರೆ.

ಕ್ಯಾಶ್ ಮೆಮೊರಿಯ 3 ಹಂತಗಳು (L1, L2, L3 Cache)

  • L1 Cache (Level 1 / Primary / Internal Cache): ಇದು ಪ್ರತಿಯೊಂದು ಸಿಪಿಯು ಕೋರ್ ಒಳಗೇ ನಿರ್ಮಿತವಾಗಿರುತ್ತದೆ. ಇದರ ಗಾತ್ರ ಅತಿ ಚಿಕ್ಕದು (32 KB - 128 KB), ಆದರೆ ಕ್ಯಾಶ್‌ಗಳಲ್ಲೇ ಅತ್ಯಂತ ವೇಗವಾದುದು.
  • L2 Cache (Level 2 Cache): ಇದು L1 ಗಿಂತ ದೊಡ್ಡದು (256 KB - 8 MB) ಮತ್ತು L1 ಗಿಂತ ಸ್ವಲ್ಪ ನಿಧಾನ.
  • L3 Cache (Level 3 / Shared Cache): ಇದು ಸಿಪಿಯುನ ಎಲ್ಲಾ ಕೋರ್‌ಗಳು ಒಟ್ಟಾಗಿ ಹಂಚಿಕೊಳ್ಳುವ (Shared) ದೊಡ್ಡ ಕ್ಯಾಶ್ (8 MB ಯಿಂದ 64 MB ವರೆಗೆ). ಇದು L1, L2 ಗಿಂತ ನಿಧಾನವಾದರೂ, RAM ಗಿಂತ ಹಲವು ಪಟ್ಟು ವೇಗವಾಗಿರುತ್ತದೆ.

🟢 B) SRAM ಮತ್ತು DRAM ನಡುವಿನ ಸಂಪೂರ್ಣ ವ್ಯತ್ಯಾಸ ಕೋಷ್ಟಕ (RAM ವಿಧಗಳು):

ವೈಶಿಷ್ಟ್ಯ SRAM (Static Random Access Memory) DRAM (Dynamic Random Access Memory)
ಇದನ್ನು ಯಾವುದರಿಂದ ಮಾಡಲಾಗಿದೆ? Transistors ಮತ್ತು Latches (Flip-Flops) (ಒಂದು ಬಿಟ್ ಸಂಗ್ರಹಿಸಲು 6 ಟ್ರಾನ್ಸಿಸ್ಟರ್ ಬಳಸುತ್ತದೆ). 1 Capacitor ಮತ್ತು 1 Transistor ನಿಂದ ಮಾಡಲ್ಪಟ್ಟಿದೆ (ಕ್ಯಾಪಾಸಿಟರ್ ಒಳಗೆ ವಿದ್ಯುತ್ ಚಾರ್ಜ್ ರೂಪದಲ್ಲಿ 0, 1 ಇರುತ್ತದೆ).
Refreshing (ಮರು-ಚಾರ್ಜ್) ಬೇಕೇ? ಬೇಡ (No Refresh needed). ವಿದ್ಯುತ್ ಇರುವವರೆಗೂ ಡೇಟಾ ಸ್ಥಿರವಾಗಿರುತ್ತದೆ (ಅದಕ್ಕೇ Static ಎನ್ನುತ್ತಾರೆ). ಹೌದು, ಪ್ರತಿ ಮಿಲಿಸೆಕೆಂಡ್‌ಗೆ ಸಾವಿರಾರು ಬಾರಿ Refresh ಆಗಲೇಬೇಕು! ಏಕೆಂದರೆ ಕ್ಯಾಪಾಸಿಟರ್ ವಿದ್ಯುತ್ ಸೋರಿಕೆಯಾಗುತ್ತಿರುತ್ತದೆ (ಅದಕ್ಕೇ Dynamic ಎನ್ನುತ್ತಾರೆ).
ವೇಗ, ಗಾತ್ರ ಮತ್ತು ಬೆಲೆ ಅತ್ಯಂತ ವೇಗವಾದುದು, ಗಾತ್ರದಲ್ಲಿ ಕಡಿಮೆ ಸಾಮರ್ಥ್ಯ (MB ಗಳಲ್ಲಿ) ಮತ್ತು ಅತ್ಯಂತ ದುಬಾರಿ. SRAM ಗಿಂತ ನಿಧಾನ, ಹೆಚ್ಚಿನ ಸಾಮರ್ಥ್ಯ (8GB, 16GB, 32GB) ಮತ್ತು ಕಡಿಮೆ ಬೆಲೆ.
ಎಲ್ಲಿ ಬಳಸುತ್ತಾರೆ? (ಪರೀಕ್ಷಾ ಪ್ರಶ್ನೆ) ಸಿಪಿಯುನ Cache Memory (L1, L2, L3) ಮತ್ತು Registers ತಯಾರಿಸಲು ಬಳಸುತ್ತಾರೆ. ಕಂಪ್ಯೂಟರ್ ಮತ್ತು ಮೊಬೈಲ್‌ನ Main Memory (RAM ಕಾರ್ಡ್ - SDRAM, DDR3, DDR4, DDR5) ತಯಾರಿಸಲು ಬಳಸುತ್ತಾರೆ.

🔒 C) ROM (Read Only Memory) ನ 4 ವಿಧಗಳು ಮತ್ತು Virtual Memory (ಚಿತ್ರಗಳು + ಸಂಪೂರ್ಣ ವಿವರಣೆ):

EPROM (UV Light Erase)

EPROM (ನೇರಳಾತೀತ ಕಿರಣದಿಂದ ಅಳಿಸುವುದು)

ಚಿಪ್ ಮೇಲಿರುವ ಪಾರದರ್ಶಕ ಕ್ವಾರ್ಟ್ಜ್ ಗಾಜಿನ ಕಿಟಕಿಯ ಮೂಲಕ UV (Ultraviolet) ಕಿರಣಗಳನ್ನು ಹಾಯಿಸಿ ಡೇಟಾ ಅಳಿಸುವ ROM.

EEPROM & Flash Memory

EEPROM (ವಿದ್ಯುತ್ ಮೂಲಕ ಅಳಿಸುವುದು)

ಯಾವುದೇ UV ಕಿರಣವಿಲ್ಲದೆ, ನೇರವಾಗಿ ವಿದ್ಯುತ್ ಸಂಕೇತಗಳ (Electrical Pulses) ಮೂಲಕ ಸೆಕೆಂಡುಗಳಲ್ಲಿ ಡೇಟಾ ಅಳಿಸಿ ಬರೆಯುವ ಚಿಪ್ (Pen Drive, SSD).

Virtual Memory (Swapping)

Virtual Memory (ವರ್ಚುವಲ್ ಮೆಮೊರಿ)

RAM ತುಂಬಿಹೋದಾಗ, ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌ನ ಸ್ವಲ್ಪ ಜಾಗವನ್ನೇ ತಾತ್ಕಾಲಿಕ RAM ನಂತೆ ಬಳಸಿಕೊಳ್ಳುವ Swapping / Paging ತಂತ್ರಜ್ಞಾನ.

🔒 ROM ವಿಧಗಳ ಸವಿವರ ಪಟ್ಟಿ (Non-Volatile / ಶಾಶ್ವತ ಮೆಮೊರಿ)

ಕಂಪ್ಯೂಟರ್ ಪವರ್ ಆಫ್ ಆದರೂ ಅಳಿಸಿಹೋಗದ ಮೆಮೊರಿಯನ್ನು ROM ಎನ್ನುತ್ತಾರೆ. ಇದರಲ್ಲೇ BIOS ಫರ್ಮ್‌ವೇರ್ ಇರುತ್ತದೆ:

  • 1. MROM (Masked ROM): ಚಿಪ್ ತಯಾರಿಸುವ ಕಾರ್ಖಾನೆಯಲ್ಲೇ ಡೇಟಾ ಮುದ್ರಿಸಲಾಗುತ್ತದೆ, ಯಾರಿಂದಲೂ ಬದಲಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ.
  • 2. PROM (Programmable ROM): ಖಾಲಿ ಚಿಪ್ ಆಗಿ ಬರುತ್ತದೆ; ಬಳಕೆದಾರರು ವಿಶೇಷ ಸಾಧನದ ಮೂಲಕ ಜೀವನದಲ್ಲಿ ಒಮ್ಮೆ ಮಾತ್ರ (One-Time Programmable - OTP) ಪ್ರೋಗ್ರಾಮ್ ಬರೆಯಬಹುದು.
  • 3. EPROM (Erasable PROM): ಇದರಲ್ಲಿ ಬರೆದ ಡೇಟಾವನ್ನು ಚಿಪ್ ಮೇಲಿರುವ ಗಾಜಿನ ಕಿಟಕಿಯ ಮೂಲಕ ಪ್ರಬಲ ನೇರಳಾತೀತ ಕಿರಣಗಳನ್ನು (Ultraviolet - UV Rays) 20-30 ನಿಮಿಷ ಹಾಯಿಸಿ ಸಂಪೂರ್ಣವಾಗಿ ಅಳಿಸಿ ಮತ್ತೆ ಬರೆಯಬಹುದು.
  • 4. EEPROM (Electrically Erasable PROM): ಬೋರ್ಡ್‌ನಿಂದ ಚಿಪ್ ತೆಗೆಯದೆ, ವಿದ್ಯುತ್ ಸಂಕೇತಗಳ (Electrical Signals) ಮೂಲಕವೇ ಬೇಕಾದ ಭಾಗವನ್ನು ಸೆಕೆಂಡುಗಳಲ್ಲಿ ಅಳಿಸಿ ಸಾವಿರಾರು ಬಾರಿ ಮರುಬರೆಯಬಹುದು. (ಇಂದಿನ NAND Flash Memory, Pen Drive, SSD, Memory Card ಎಲ್ಲವೂ EEPROM ನ ಮುಂದುವರಿದ ರೂಪಗಳಾಗಿವೆ!).

🪄 Virtual Memory (ವರ್ಚುವಲ್ ಮೆಮೊರಿ) ಎಂದರೇನು?

ಏನಿದು? ಇದು ಭೌತಿಕವಾಗಿ ಕಣ್ಣಿಗೆ ಕಾಣುವ ಮೆಮೊರಿ ಚಿಪ್ ಅಲ್ಲ; ಬದಲಿಗೆ ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ (OS) ಸೃಷ್ಟಿಸುವ ಒಂದು ಭ್ರಮಾತ್ಮಕ ಮೆಮೊರಿ ತಂತ್ರಜ್ಞಾನ (Illusion of larger RAM).

ಇದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ?
ಉದಾಹರಣೆಗೆ ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಕೇವಲ 4 GB RAM ಇದೆ ಎಂದಿಟ್ಟುಕೊಳ್ಳಿ. ನೀವು ದೊಡ್ಡ ಗೇಮ್ ಅಥವಾ ಹತ್ತು ಆ್ಯಪ್‌ಗಳನ್ನು ಒಟ್ಟಿಗೆ ಓಪನ್ ಮಾಡಿದಾಗ 4 GB RAM ತುಂಬಿಹೋಗುತ್ತದೆ. ಆಗ ಕಂಪ್ಯೂಟರ್ ಹ್ಯಾಂಗ್ ಆಗಬಾರದೆಂದು, ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ Hard Disk ಅಥವಾ SSD ಯಲ್ಲಿರುವ ಸ್ವಲ್ಪ ಖಾಲಿ ಜಾಗವನ್ನೇ (ಉದಾ: ಇನ್ನೊಂದು 4 GB ಯನ್ನು) ತಾತ್ಕಾಲಿಕ RAM ನಂತೆ ಬಳಸಿಕೊಳ್ಳುತ್ತದೆ!

  • ಬಳಕೆಯಲ್ಲಿಲ್ಲದ ಫೈಲ್‌‌ಗಳನ್ನು RAM ನಿಂದ ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌ಗೆ ಕಳುಹಿಸಿ, ಬೇಕಾದ ಫೈಲ್ ತರುವ ಪ್ರಕ್ರಿಯೆಯನ್ನು Swapping / Paging ಎನ್ನುತ್ತಾರೆ.
  • ವಿಂಡೋಸ್‌ನಲ್ಲಿ ಆ ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ಜಾಗವನ್ನು Pagefile.sys ಎಂದೂ ಲಿನಕ್ಸ್‌ನಲ್ಲಿ Swap Partition ಎಂದೂ ಕರೆಯುತ್ತಾರೆ.
ಭಾಗ 5: ದ್ವಿತೀಯಕ ಸಂಗ್ರಹಣಾ ಸಾಧನಗಳು ಮತ್ತು ಮೆಮೊರಿ ಅಳತೆ ಕೋಷ್ಟಕ

5. ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ಒಳರಚನೆ (Tracks, Sectors), ಆಪ್ಟಿಕಲ್ ಡಿಸ್ಕ್‌ಗಳು ಮತ್ತು Bit ನಿಂದ Geopbyte ವರೆಗಿನ ಅಳತೆಗಳು

💿 ಲೈವ್ ಡಯಾಗ್ರಾಮ್ 5: ಹಾರ್ಡ್ ಡಿಸ್ಕ್ ತಟ್ಟೆಯ ಒಳರಚನೆ (Track vs Sector vs Cluster) ಮತ್ತು Access Time

🔹 Platter: Iron Oxide ಕಾಂತೀಯ ಲೇಪನವಿರುವ ಲೋಹದ ತಿರುಗುವ ತಟ್ಟೆ.

🔹 Track (ಟ್ರ್ಯಾಕ್): ತಟ್ಟೆಯ ಮೇಲಿರುವ ಏಕಕೇಂದ್ರಿತ ವೃತ್ತಾಕಾರದ ಗೆರೆಗಳು (Concentric circles).

🔹 Sector (ಸೆಕ್ಟರ್): ಟ್ರ್ಯಾಕ್‌ನ ಚಿಕ್ಕ ಉಪವಿಭಾಗ. ಇದು ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌ನ ಅತ್ಯಂತ ಚಿಕ್ಕ ಶೇಖರಣಾ ಘಟಕ = 512 Bytes (ಅಥವಾ 4 KB).

🔹 Cluster (ಕ್ಲಸ್ಟರ್): ಫೈಲ್ ಸೇವ್ ಮಾಡಲು OS ಬಳಸುವ ಪಕ್ಕದ ಸೆಕ್ಟರ್‌ಗಳ ಗುಂಪು.

🔹 Cylinder (ಸಿಲಿಂಡರ್): ಒಂದರ ಮೇಲೊಂದಿರುವ ಎಲ್ಲಾ ತಟ್ಟೆಗಳ ಒಂದೇ ಸಂಖ್ಯೆಯ ಟ್ರ್ಯಾಕ್‌ಗಳ ನೇರ ಜೋಡಣೆ.

💿 1. ಕಾಂತೀಯ ಸಂಗ್ರಹಣೆ (Magnetic Storage: HDD, Floppy, Tape)

  • Hard Disk (HDD): ಅಲ್ಯೂಮಿನಿಯಂ ಅಥವಾ ಗಾಜಿನ ತಟ್ಟೆಯ (Platter) ಮೇಲೆ Iron Oxide (ಕಬ್ಬಿಣದ ಆಕ್ಸೈಡ್) ಕಾಂತೀಯ ಲೇಪನವಿರುತ್ತದೆ. ತಟ್ಟೆಯು ನಿಮಿಷಕ್ಕೆ 5400 ಅಥವಾ 7200 RPM (Revolutions Per Minute) ವೇಗದಲ್ಲಿ ತಿರುಗುತ್ತದೆ.
  • Formatting (ಫಾರ್ಮ್ಯಾಟಿಂಗ್): ಹೊಸ ಡಿಸ್ಕ್ ಮೇಲೆ ಡೇಟಾ ಬರೆಯಲು ಅನುಕೂಲವಾಗುವಂತೆ ವೃತ್ತಾಕಾರದ Tracks ಮತ್ತು Sectors (1 Sector = 512 Bytes) ರಚಿಸುವ ಪ್ರಕ್ರಿಯೆಯನ್ನು Disk Formatting ಎನ್ನುತ್ತಾರೆ.
  • Floppy Disk (ಫ್ಲಾಪಿ ಡಿಸ್ಕ್): ಹಳೆಯ ಕಾಲದ ಬಾಗುವ ಕಾಂತೀಯ ಡಿಸ್ಕ್. ಇದರ ಪ್ರಮುಖ ಸಾಮರ್ಥ್ಯ: 3.5 ಇಂಚಿನ ಡಿಸ್ಕ್ = 1.44 MB (5.25 ಇಂಚು = 1.2 MB).

📀 2. ಆಪ್ಟಿಕಲ್ ಡಿಸ್ಕ್‌ಗಳು (Optical Storage - Laser ಬಳಕೆ)

ಇವುಗಳಲ್ಲಿ ಡೇಟಾ ಬರೆಯಲು (Burn ಮಾಡಲು) ಮತ್ತು ಓದಲು ಲೇಸರ್ ಬೆಳಕಿನ ಕಿರಣ (Laser Beam) ಬಳಸಲಾಗುತ್ತದೆ:

  • CD (Compact Disc): ಸಾಮರ್ಥ್ಯ = 700 MB (780 nm ಕೆಂಪು ಲೇಸರ್ ಬಳಕೆ).
    • CD-ROM: ಓದಲು ಮಾತ್ರ | CD-R (WORM - Write Once Read Many): ಒಮ್ಮೆ ಮಾತ್ರ ಬರೆಯಬಹುದು | CD-RW: ಅಳಿಸಿ ಮತ್ತೆ ಬರೆಯಬಹುದು.
  • DVD (Digital Versatile / Video Disc): ಸಾಮರ್ಥ್ಯ = 4.7 GB (Single Layer) ನಿಂದ 8.5 GB (Dual Layer) (650 nm ಕೆಂಪು ಲೇಸರ್).
  • Blu-Ray Disc (BD): ಸಾಮರ್ಥ್ಯ = 25 GB (Single Layer) ನಿಂದ 50 GB (Dual Layer). ಇದರಲ್ಲಿ ಅತಿ ಕಡಿಮೆ ತರಂಗಾಂತರದ (405 nm) ನೀಲಿ-ನೇರಳೆ ಲೇಸರ್ (Blue-Violet Laser) ಬಳಸುವುದರಿಂದ ಅತಿ ಹೆಚ್ಚು HD ವಿಡಿಯೋ ಹಿಡಿಯುತ್ತದೆ!

⏱️ 3. Disk Access Time (ಪರೀಕ್ಷಾ ಸೂತ್ರ)

ಹಾರ್ಡ್ ಡಿಸ್ಕ್‌ನಿಂದ ಡೇಟಾ ತೆಗೆದುಕೊಳ್ಳಲು ತಗುಲುವ ಸಮಯವು 3 ಅಂಶಗಳನ್ನು ಒಳಗೊಂಡಿರುತ್ತದೆ:
1. Seek Time: Read/Write ಹೆಡ್ ಸರಿಯಾದ Track ತಲುಪಲು ತೆಗೆದುಕೊಳ್ಳುವ ಸಮಯ.
2. Rotational Latency: ತಟ್ಟೆ ತಿರುಗಿ ಸರಿಯಾದ Sector ಹೆಡ್ ಕೆಳಗೆ ಬರಲು ತೆಗೆದುಕೊಳ್ಳುವ ಸಮಯ.
3. Transfer Rate: ಡೇಟಾ ಓದಿ ಕಳುಹಿಸುವ ಸಮಯ.

📼 4. Sequential vs Direct Access Storage

  • Sequential Access (ಅನುಕ್ರಮ ಪ್ರವೇಶ): ಡೇಟಾವನ್ನು ಮೊದಲಿನಿಂದ ವரிசೆಯಾಗಿ ಮಾತ್ರ ಓದಲು ಸಾಧ್ಯ — ಉದಾ: Magnetic Tape (ಕ್ಯಾಸೆಟ್ ಟೇಪ್).
  • Direct / Random Access (ನೇರ ಪ್ರವೇಶ): ಬೇಕಾದ ಫೈಲ್‌ಗೆ ನೇರವಾಗಿ ಜಂಪ್ ಆಗಿ ಓದಲು ಸಾಧ್ಯ — ಉದಾ: RAM, Hard Disk, SSD, CD/DVD, Pen Drive.

📊 ಮೆಮೊರಿ ಅಳತೆಯ ಸಂಪೂರ್ಣ ಕೋಷ್ಟಕ (Memory Units Hierarchy - ಕಡ್ಡಾಯವಾಗಿ ನೆನಪಿಡಿ):

ಮೆಮೊರಿ ಘಟಕ (Unit Name) ಸಮಾನ ಮೌಲ್ಯ (Exact Equivalent) 2 ರ ಘಾತಾಂಕ ($2^n$) ಮತ್ತು ಪರೀಕ್ಷಾ ವಿಶೇಷತೆ
1 Bit (Binary Digit) 0 ಅಥವಾ 1 ಕಂಪ್ಯೂಟರ್ ಮೆಮೊರಿಯ ಅತ್ಯಂತ ಚಿಕ್ಕ ಘಟಕ (Smallest unit of data).
1 Nibble (ನಿಬ್ಬಲ್) 4 Bits ಅರ್ಧ ಬೈಟ್ (Half a Byte = 1 Hexadecimal digit).
1 Byte (ಬೈಟ್ / Octet) 8 Bits ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಒಂದು ಅಕ್ಷರವನ್ನು (ಉದಾ: 'A' ಅಥವಾ '5') ಸಂಗ್ರಹಿಸಲು ಬೇಕಾಗುವ ಮೂಲ ಘಟಕ.
1 Kilobyte (KB) 1024 Bytes $2^{10}$ Bytes (ದಶಮಾಂಶದಲ್ಲಿ $\approx 10^3$).
1 Megabyte (MB) 1024 KB $2^{20}$ Bytes ($\approx 10^6$ / 1 Million Bytes).
1 Gigabyte (GB) 1024 MB $2^{30}$ Bytes ($\approx 10^9$ / 1 Billion Bytes).
1 Terabyte (TB) 1024 GB $2^{40}$ Bytes ($\approx 10^{12}$ / 1 Trillion Bytes).
1 Petabyte (PB) 1024 TB $2^{50}$ Bytes ($\approx 10^{15}$ Bytes).
1 Exabyte (EB) 1024 PB $2^{60}$ Bytes ($\approx 10^{18}$ Bytes).
1 Zettabyte (ZB) 1024 EB $2^{70}$ Bytes ($\approx 10^{21}$ Bytes).
1 Yottabyte (YB) 1024 ZB $2^{80}$ Bytes (ಇದರ ನಂತರ Brontobyte [BB] ಮತ್ತು Geopbyte ಬರುತ್ತವೆ).
ಭಾಗ 6: ಇನ್‌ಪುಟ್ ಮತ್ತು ಔಟ್‌ಪುಟ್ ಸಾಧನಗಳ ಸಂಪೂರ್ಣ ವಿಶ್ವಕೋಶ + ಲೈವ್ ಚಿತ್ರಗಳು

6. ಕೀಬೋರ್ಡ್, ಮೌಸ್, ಸ್ಕ್ಯಾನರ್‌ಗಳು, ಮಾನಿಟರ್ ಮತ್ತು ಪ್ರಿಂಟರ್‌ಗಳ ಆಳವಾದ ವಿವರಣೆ

ಸ್ಪರ್ಧಾತ್ಮಕ ಪರೀಕ್ಷೆಗಳಲ್ಲಿ ಹಾರ್ಡ್‌ವೇರ್ ವಿಭಾಗದಿಂದ ಅತಿ ಹೆಚ್ಚು ಪ್ರಶ್ನೆಗಳು ಬರುವ ಇನ್‌‌ಪುಟ್ ಮತ್ತು ಔಟ್‌ಪುಟ್ ಸಾಧನಗಳ ಚಿತ್ರಗಳು ಮತ್ತು ಸಂಪೂರ್ಣ ವಿವರಣೆ:

1. QWERTY Keyboard (104 Keys)

1. ಕೀಬೋರ್ಡ್ (104 ಕೀಲಿಗಳ ವಿನ್ಯಾಸ)

• Function Keys: F1 ರಿಂದ F12 (12 ಕೀಗಳು).
• Modifier Keys: Ctrl, Alt, Shift.
• Toggle Keys: Caps Lock, Num Lock, Scroll Lock.

2. Mouse & Trackball

2. ಮೌಸ್ ಮತ್ತು ಟ್ರ್ಯಾಕ್‌ಬಾಲ್

ಮೌಸ್ ಅನ್ನು ಮೇಜಿನ ಮೇಲೆ ಚಲಿಸಿದರೆ, Trackball ಒಂದೇ ಕಡೆ ಇರುತ್ತದೆ; ಅದರ ಮೇಲಿರುವ ಚೆಂಡನ್ನು ಬೆರಳಿನಿಂದ ತಿರುಗಿಸಿ ಕರ್ಸರ್ ನಡೆಸಲಾಗುತ್ತದೆ (CAD/ಅಲ್ಟ್ರಾಸೌಂಡ್).

3. Joystick & Stylus Pen

3. ಜಾಯ್‌ಸ್ಟಿಕ್ ಮತ್ತು ಲೈಟ್ ಪೆನ್

ವಿಡಿಯೋ ಗೇಮ್ಸ್ ಮತ್ತು ವಿಮಾನ ತರಬೇತಿಯಲ್ಲಿ $360^\circ$ ತಿರುಗುವ Joystick ಬಳಸಿದರೆ, ಪರದೆಯ ಮೇಲೆ ನೇರವಾಗಿ ಚಿತ್ರ ಬಿಡಿಸಲು Light Pen / Stylus ಬಳಸುತ್ತಾರೆ.

4. MICR (ಬ್ಯಾಂಕ್ ಚೆಕ್ ಕೋಡ್)

4. MICR (Magnetic Ink Character)

ಬ್ಯಾಂಕ್ ಚೆಕ್ ಕೆಳಭಾಗದಲ್ಲಿ Iron Oxide ಕಾಂತೀಯ ಶಾಯಿಯಿಂದ ಬರೆದ 9 ಅಂಕಿಯ ಕೋಡ್ ಓದುವ ಯಂತ್ರ (ಮೊದಲ 3=ನಗರ, ಮಧ್ಯದ 3=ಬ್ಯಾಂಕ್, ಕೊನೆಯ 3=ಶಾಖೆ).

5. Impact: Dot-Matrix Printer

5. ಇಂಪ್ಯಾಕ್ಟ್ ಪ್ರಿಂಟರ್ (Dot Matrix)

9 ಅಥವಾ 24 ಪಿನ್‌ಗಳು ಇಂಕ್ ರಿಬ್ಬನ್ ಮತ್ತು ಕಾಗದಕ್ಕೆ ಭೌತಿಕವಾಗಿ ಬಡಿದು (Strike) ಚುಕ್ಕೆಗಳ ರೂಪದಲ್ಲಿ ಮುದ್ರಿಸುತ್ತವೆ. ವೇಗದ ಮಾಪನ: CPS (Characters Per Second).

6. Non-Impact: Laser Printer

6. ಲೇಸರ್ ಪ್ರಿಂಟರ್ (Non-Impact)

ಯಾವುದೇ ಶಬ್ದವಿಲ್ಲದೆ, ಲೇಸರ್ ಕಿರಣ, ತಿರುಗುವ ಡ್ರಮ್ ಮತ್ತು ಒಣ ಶಾಯಿ ಪುಡಿ (Dry Toner Powder) ಬಳಸಿ ಇಡೀ ಪುಟವನ್ನು ಒಮ್ಮೆಲೇ ಮುದ್ರಿಸುತ್ತದೆ. ವೇಗ: PPM.

7. Plotter (ನೀಲನಕ್ಷೆ ಮುದ್ರಕ)

7. ಪ್ಲಾಟರ್ (Plotter - Vector Output)

ಕಟ್ಟಡಗಳ ನೀಲನಕ್ಷೆ (Blueprints), ಭೂಪಟಗಳು (Maps), CAD ವಿನ್ಯಾಸ ಮತ್ತು ಬೃಹತ್ ಫ್ಲೆಕ್ಸ್ ಬ್ಯಾನರ್‌ಗಳನ್ನು ಪೆನ್/ಬೆಲ್ಟ್ ಮೂಲಕ ನಿಖರವಾಗಿ ಬಿಡಿಸುವ ಬೃಹತ್ ಸಾಧನ.

8. CRT vs LED/OLED Monitor

8. ಮಾನಿಟರ್ ತಂತ್ರಜ್ಞಾನ (CRT ರಿಂದ OLED)

ಹಳೆಯ CRT ಯಲ್ಲಿ ಎಲೆಕ್ಟ್ರಾನ್ ಗನ್ ಮತ್ತು ರಂಜಕ (Phosphor) ಇತ್ತು. ಆಧುನಿಕ LCD, LED ಮತ್ತು AMOLED ಪರದೆಗಳು ತೆಳ್ಳಗಿದ್ದು ಕಡಿಮೆ ವಿದ್ಯುತ್ ಬಳಸುತ್ತವೆ.

⌨️ A) ಇನ್‌ಪುಟ್ ಸಾಧನಗಳ ಸವಿವರ ಪಠ್ಯ (Input Devices - ಕಂಪ್ಯೂಟರ್ ಒಳಗೆ ಆದೇಶ ನೀಡುವವು):

1. ಕೀಬೋರ್ಡ್ (Keyboard - ಕ್ರಿಸ್ಟೋಫರ್ ಲ್ಯಾಥಮ್ ಶೋಲ್ಸ್)

ಪ್ರಮಾಣಿತ QWERTY ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ ಸಾಮಾನ್ಯವಾಗಿ 104 ಕೀಲಿಗಳು (Keys) ಇರುತ್ತವೆ. ಕೀಲಿಗಳ ಪ್ರಮುಖ ವಿಭಾಗಗಳು:

  • Function Keys (F1 ರಿಂದ F12 - ಒಟ್ಟು 12): ಮೇಲ್ಭಾಗದ ಸಾಲಿನಲ್ಲಿರುವ ವಿಶೇಷ ಕಾರ್ಯದ ಕೀಲಿಗಳು (ಉದಾ: F1 = Help, F2 = Rename, F5 = Refresh, F7 = Spell Check, F12 = Save As).
  • Modifier / Combination Keys: Ctrl, Alt, Shift — ಇವು ತಾವಾಗಿಯೇ ಏನನ್ನೂ ಮಾಡುವುದಿಲ್ಲ; ಬೇರೆ ಕೀಲಿಗಳ ಜೊತೆ ಸೇರಿ ಕೆಲಸ ಮಾಡುತ್ತವೆ (ಉದಾ: Ctrl + C).
  • Toggle Keys (ಆನ್/ಆಫ್ ಕೀಲಿಗಳು): ಒಮ್ಮೆ ಒತ್ತಿದರೆ ಆನ್ ಆಗುವ ಮತ್ತು ಮತ್ತೊಮ್ಮೆ ಒತ್ತಿದರೆ ಆಫ್ ಆಗುವ ಕೀಲಿಗಳು — Caps Lock, Num Lock, Scroll Lock, Insert.
  • Navigation Keys: Arrow Keys (4), Home, End, Page Up, Page Down.

2. ಪಾಯಿಂಟಿಂಗ್ ಸಾಧನಗಳು (Pointing Devices)

ಪರದೆಯ ಮೇಲಿನ ಕರ್ಸರ್ (Cursor/Pointer) ಅನ್ನು ಚಲಿಸಲು ಬಳಸುವ ಸಾಧನಗಳು:

  • Mouse (ಮೌಸ್): ಡಗ್ಲಾಸ್ ಎಂಗೆಲ್‌ಬಾರ್ಟ್ (Douglas Engelbart - 1964) ಕಂಡುಹಿಡಿದರು. (Left Click = ಆಯ್ಕೆ ಮಾಡಲು, Double Click = ಓಪನ್ ಮಾಡಲು, Right Click = Properties ಪಟ್ಟಿ ತೆರೆಯಲು).
  • Trackball (ಟ್ರ್ಯಾಕ್‌ಬಾಲ್): ಮೌಸ್ ಅನ್ನು ತಲೆಕೆಳಗಾಗಿ ಇಟ್ಟಂತೆ ಇರುತ್ತದೆ; ಮೇಲೆ ಇರುವ ಚೆಂಡನ್ನು ಬೆರಳಿನಿಂದ ತಿರುಗಿಸಿ ಕರ್ಸರ್ ನಡೆಸಲಾಗುತ್ತದೆ (CAD/CAM ವಿನ್ಯಾಸ ಮತ್ತು ಅಲ್ಟ್ರಾಸೌಂಡ್ ಮಷಿನ್‌ಗಳಲ್ಲಿ ಬಳಕೆ).
  • Joystick (ಜಾಯ್‌ಸ್ಟಿಕ್): ವಿಡಿಯೋ ಗೇಮ್ಸ್ ಆಡಲು ಮತ್ತು ವಿಮಾನದ ಸಿಮ್ಯುಲೇಟರ್‌ಗಳಲ್ಲಿ ಬಳಸುವ ಹಿಡಿಕೆ (ಇದು $360^\circ$ ತಿರುಗುತ್ತದೆ).
  • Light Pen & Stylus: ಪರದೆಯ ಮೇಲೆ ನೇರವಾಗಿ ಚಿತ್ರ ಬಿಡಿಸಲು ಮತ್ತು ಸಹಿ ಮಾಡಲು ಬಳಸುವ ಪೆನ್.

3. 4 ವಿಶೇಷ ಸ್ಕ್ಯಾನರ್‌ಗಳು (ಪರೀಕ್ಷೆಯಲ್ಲಿ ಕಡ್ಡಾಯವಾಗಿ ಕೇಳುವವು)

  • OMR (Optical Mark Recognition / Reader): ಸ್ಪರ್ಧಾತ್ಮಕ ಪರೀಕ್ಷೆಗಳ ಬಹುಆಯ್ಕೆ ಉತ್ತರ ಪತ್ರಿಕೆಯಲ್ಲಿ (MCQ Sheet) ಪೆನ್/ಪೆನ್ಸಿಲ್‌ನಿಂದ ತುಂಬಿದ ವೃತ್ತಗಳನ್ನು ಬೆಳಕಿನ ಮೂಲಕ ಗುರುತಿಸುವ ಸಾಧನ.
  • MICR (Magnetic Ink Character Recognition): ಬ್ಯಾಂಕ್ ಚೆಕ್‌ಗಳ ಕೆಳಭಾಗದಲ್ಲಿ Iron Oxide (ಕಬ್ಬಿಣದ ಆಕ್ಸೈಡ್) ಕಾಂತೀಯ ಶಾಯಿಯಿಂದ ಮುದ್ರಿಸಲಾದ 9 ಅಂಕಿಗಳ ಕೋಡ್ ಅನ್ನು ಓದುವ ಯಂತ್ರ (ಮೊದಲ 3 ಅಂಕಿ = ನಗರ, ಮಧ್ಯದ 3 = ಬ್ಯಾಂಕ್, ಕೊನೆಯ 3 = ಶಾಖೆ).
  • OCR (Optical Character Recognition): ಸ್ಕ್ಯಾನ್ ಮಾಡಿದ ಪುಸ್ತಕ ಅಥವಾ ಫೋಟೋದ ಮೇಲಿರುವ ಮುದ್ರಿತ ಅಕ್ಷರಗಳನ್ನು ಗುರುತಿಸಿ, ಎಡಿಟ್ ಮಾಡಬಹುದಾದ ಟೆಕ್ಸ್ಟ್ (Editable Text) ಆಗಿ ಬದಲಿಸುವ ತಂತ್ರಜ್ಞಾನ.
  • BCR (Barcode Reader) & QR Code: ಉತ್ಪನ್ನಗಳ ಮೇಲಿನ ಕಪ್ಪು-ಬಿಳಿ ಉದ್ದ ಗೆರೆಗಳನ್ನು (Universal Product Code) ಓದುವ ಲೇಸರ್ ಸಾಧನ. (QR Code = Quick Response Code - 2D ಮ್ಯಾಟ್ರಿಕ್ಸ್ ಕೋಡ್).

🖨️ B) ಪ್ರಿಂಟರ್‌ಗಳ ಸಂಪೂರ್ಣ ವರ್ಗೀಕರಣ (Impact vs Non-Impact Printers - ಅತಿ ಮುಖ್ಯ):

ಪ್ರಿಂಟರ್ ಕಂಪ್ಯೂಟರ್‌ನ ಒಳಗಿರುವ Soft Copy (ಡಿಜಿಟಲ್ ಫೈಲ್) ಯನ್ನು ಕಾಗದದ ಮೇಲಿನ Hard Copy (ಮುದ್ರಿತ ಪ್ರತಿ) ಆಗಿ ಬದಲಿಸುವ Output ಸಾಧನವಾಗಿದೆ. ಪ್ರಿಂಟರ್‌ನ ಗುಣಮಟ್ಟವನ್ನು DPI (Dots Per Inch) ನಲ್ಲಿ ಅಳೆಯುತ್ತಾರೆ.
ಪ್ರಿಂಟರ್ ವರ್ಗ ಪ್ರಿಂಟರ್ ಹೆಸರು ಇದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ? ಮತ್ತು ವೇಗದ ಮಾಪನ
1. Impact Printers (ಇಂಪ್ಯಾಕ್ಟ್ ಪ್ರಿಂಟರ್‌ಗಳು)
ಟೈಪ್‌ರೈಟರ್‌ನಂತೆ ಲೋಹದ ಪಿನ್ ಅಥವಾ ಹ್ಯಾಮರ್ ಶಾಯಿಯ ರಿಬ್ಬನ್ ಹಾಗೂ ಕಾಗದಕ್ಕೆ ಭೌತಿಕವಾಗಿ ಬಡಿದು (Strike) ಅಚ್ಚು ಮೂಡಿಸುತ್ತವೆ. ಇವು ಹೆಚ್ಚು ಶಬ್ದ ಮಾಡುತ್ತವೆ.		 A) Dot Matrix Printer ಇದರ ಪ್ರಿಂಟ್ ಹೆಡ್‌ನಲ್ಲಿ 9 ಅಥವಾ 24 ಸಣ್ಣ ಪಿನ್‌ಗಳಿರುತ್ತವೆ. ಅವು ಇಂಕ್ ರಿಬ್ಬನ್ ಮೇಲೆ ಬಡಿದು ಸಣ್ಣ ಚುಕ್ಕೆಗಳ (Dots) ಮೂಲಕ ಅಕ್ಷರ ಮುದ್ರಿಸುತ್ತವೆ. (ಇಂದಿಗೂ ಪೋಸ್ಟ್ ಆಫೀಸ್, ಕೆಎಸ್ಆರ್‌ಟಿಸಿ ಮತ್ತು ಬ್ಯಾಂಕ್‌ಗಳಲ್ಲಿ ಕಾರ್ಬನ್ ಕಾಪಿ ಬಿಲ್ ಪ್ರಿಂಟ್ ಮಾಡಲು ಬಳಸುತ್ತಾರೆ).
📏 ವೇಗದ ಅಳತೆ: CPS (Characters Per Second).
B) Daisy Wheel Printer ಡೈಸಿ ಹೂವಿನ ದಳಗಳಂತಿರುವ ಚಕ್ರದ ತುದಿಯಲ್ಲಿ ಅಕ್ಷರಗಳಿರುತ್ತವೆ. ಚಕ್ರ ತಿರುಗಿ ಬೇಕಾದ ಅಕ್ಷರವನ್ನು ಕಾಗದಕ್ಕೆ ಬಡಿಯುತ್ತದೆ. (ಇದರಲ್ಲಿ ಗ್ರಾಫಿಕ್ಸ್/ಚಿತ್ರ ಮುದ್ರಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ). ವೇಗದ ಅಳತೆ: CPS.
C) Line Printer (Drum / Chain / Band) ಒಮ್ಮೆಗೆ ಒಂದೊಂದು ಅಕ್ಷರದ ಬದಲು ಇಡೀ ಒಂದು ಸಾಲನ್ನೇ (Whole Line) ಒಂದೇ ಬಾರಿಗೆ ವೇಗವಾಗಿ ಮುದ್ರಿಸುವ ದೊಡ್ಡ ಪ್ರಿಂಟರ್.
📏 ವೇಗದ ಅಳತೆ: LPM (Lines Per Minute).
2. Non-Impact Printers (ನಾನ್-ಇಂಪ್ಯಾಕ್ಟ್ ಪ್ರಿಂಟರ್‌ಗಳು)
ಕಾಗದಕ್ಕೆ ಯಾವುದೇ ಪಿನ್ ಬಡಿಯುವುದಿಲ್ಲ! ಶಾಯಿ ಸಿಂಪಡಣೆ, ಲೇಸರ್ ಅಥವಾ ಶಾಖದ ಮೂಲಕ ಶಬ್ದವಿಲ್ಲದೆ ಮತ್ತು ಅತ್ಯಂತ ವೇಗವಾಗಿ ಮುದ್ರಿಸುತ್ತವೆ.		 A) Inkjet Printer ಸೂಕ್ಷ್ಮ ನಳಿಕೆಗಳ (Nozzles) ಮೂಲಕ ಕಾಗದದ ಮೇಲೆ ದ್ರವ ರೂಪದ ಶಾಯಿಯ ಹನಿಗಳನ್ನು (Liquid Ink droplets - CMYK ಬಣ್ಣಗಳು) ಸಿಂಪಡಿಸಿ ಬಣ್ಣದ ಫೋಟೋ ಮತ್ತು ದಾಖಲೆ ಮುದ್ರಿಸುತ್ತದೆ.
📏 ವೇಗದ ಅಳತೆ: PPM (Pages Per Minute).
B) Laser Printer (ಅತ್ಯಂತ ವೇಗದ ಪ್ರಿಂಟರ್) ಜಿರಾಕ್ಸ್ ಮಷಿನ್‌ನಂತೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಇದರಲ್ಲಿ ದ್ರವ ಶಾಯಿ ಇರುವುದಿಲ್ಲ; ಬದಲಿಗೆ ಒಣ ಪುಡಿ ಶಾಯಿ (Dry Powder Ink = Toner), ಲೇಸರ್ ಕಿರಣ ಮತ್ತು ಫೋಟೋಸೆನ್ಸಿಟಿವ್ ಡ್ರಮ್ ಬಳಸಿ ಇಡೀ ಪುಟವನ್ನು ಸೆಕೆಂಡುಗಳಲ್ಲಿ ಮುದ್ರಿಸುತ್ತದೆ.
📏 ವೇಗದ ಅಳತೆ: PPM (Pages Per Minute).
C) Thermal Printer ಇದರಲ್ಲಿ ಯಾವುದೇ ಶಾಯಿ (Ink) ಬಳಸುವುದಿಲ್ಲ! ಬದಲಿಗೆ ಶಾಖಕ್ಕೆ ಕಪ್ಪಾಗುವ ವಿಶೇಷ ರಾಸಾಯನಿಕ ಕಾಗದದ (Thermochromic Paper) ಮೇಲೆ ಶಾಖ (Heat) ನೀಡಿ ಮುದ್ರಿಸುತ್ತದೆ.
🎯 ಬಳಕೆ: ಬಸ್ ಟಿಕೆಟ್ ಮಷಿನ್, ATM ರಸೀದಿ, ಸೂಪರ್ ಮಾರ್ಕೆಟ್ ಬಿಲ್.
D) Plotter (ಪ್ಲಾಟರ್) ಇಂಜಿನಿಯರಿಂಗ್ ಕಟ್ಟಡದ ನೀಲನಕ್ಷೆಗಳು (Blueprints), ಬೃಹತ್ ಬ್ಯಾನರ್‌ಗಳು, ಭೂಪಟಗಳು (Maps) ಮತ್ತು CAD ವಿನ್ಯಾಸಗಳನ್ನು ರೇಖೆಗಳ ಮೂಲಕ ನಿಖರವಾಗಿ ಬಿಡಿಸುವ ಬೃಹತ್ ಗಾತ್ರದ ವಿಶೇಷ ಮುದ್ರಣ ಯಂತ್ರ (Drum & Flatbed Plotter).

🖥️ C) ಮಾನಿಟರ್ ವಿಧಗಳು (CRT, LCD, LED, OLED) ಮತ್ತು ಎರಡೂ ಕೆಲಸ ಮಾಡುವ ಸಾಧನಗಳು (Both I/O):

ಮಾನಿಟರ್‌ನ 4 ತಂತ್ರಜ್ಞಾನಗಳು (VDU - Visual Display Unit)

  • 1. CRT (Cathode Ray Tube): ಹಳೆಯ ಕಾಲದ ಟಿವಿಯಂತೆ ದೊಡ್ಡದಾಗಿದ್ದ ಮಾನಿಟರ್. ಇದರ ಒಳಗೆ ಎಲೆಕ್ಟ್ರಾನ್ ಗನ್ ಪರದೆಯ ಮೇಲಿನ Phosphor (ರಂಜಕ) ಲೇಪನಕ್ಕೆ ಬಡಿದು ಚಿತ್ರ ಮೂಡಿಸುತ್ತಿತ್ತು.
  • 2. LCD (Liquid Crystal Display): ಎರಡು ಗಾಜಿನ ಪದರಗಳ ನಡುವೆ ದ್ರವ ರೂಪದ ಹರಳುಗಳನ್ನು (Liquid Crystals) ಇಟ್ಟು CCFL ಹಿಂಬೆಳಕಿನ ಮೂಲಕ ಚಿತ್ರ ತೋರಿಸುವ ತೆಳ್ಳಗಿನ ಪರದೆ (ಇದರಲ್ಲಿ TFT - Thin Film Transistor ಬಳಕೆಯಾಗುತ್ತದೆ).
  • 3. LED (Light Emitting Diode): ಹಿಂಬೆಳಕಿಗಾಗಿ ಸಣ್ಣ LED ಬಲ್ಬ್‌ಗಳನ್ನು ಬಳಸುವ ಆಧುನಿಕ ಪರದೆ (ಕಡಿಮೆ ವಿದ್ಯುತ್ ಮತ್ತು ಹೆಚ್ಚು ಪ್ರಕಾಶಮಾನ).
  • 4. OLED / AMOLED: (Active-Matrix Organic Light Emitting Diode) ಇಂದಿನ ಸ್ಮಾರ್ಟ್‌ಫೋನ್ ಮತ್ತು ದುಬಾರಿ ಟಿವಿಗಳಲ್ಲಿರುವ ಪರದೆ (ಪ್ರತಿ ಪಿಕ್ಸೆಲ್ ಸ್ವತಃ ಬೆಳಗುತ್ತದೆ).

🔄 Both Input & Output Devices (ಪರೀಕ್ಷಾ ಟ್ರಿಕ್ ಪ್ರಶ್ನೆ!)

ಪರೀಕ್ಷೆಯಲ್ಲಿ "ಕೆಳಗಿನವುಗಳಲ್ಲಿ ಯಾವುದು ಇನ್‌ಪುಟ್ ಮತ್ತು ಔಟ್‌ಪುಟ್ ಎರಡೂ ಆಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ?" ಎಂದು ಕೇಳಿದರೆ ಈ 5 ಸಾಧನಗಳನ್ನು ನೆನಪಿಡಿ:

  • 1. Touchscreen (ಟಚ್‌ಸ್ಕ್ರೀನ್): ಚಿತ್ರ ತೋರಿಸುತ್ತದೆ (Output) + ನಮ್ಮ ಬೆರಳಿನ ಸ್ಪರ್ಶ ಸ್ವೀಕರಿಸುತ್ತದೆ (Input).
  • 2. Modem (ಮೋಡೆಮ್ - Modulator-Demodulator): ಡೇಟಾ ಕಳುಹಿಸುತ್ತದೆ ಮತ್ತು ಸ್ವೀಕರಿಸುತ್ತದೆ.
  • 3. Headset (ಹೆಡ್‌ಸೆಟ್): ಇದರಲ್ಲಿ ಕೇಳಿಸಿಕೊಳ್ಳಲು Speaker (Output) ಮತ್ತು ಮಾತನಾಡಲು Microphone (Input) ಎರಡೂ ಇರುತ್ತವೆ.
  • 4. Multifunction Printer (MFP / All-in-One): ಇದರಲ್ಲಿ Scanner (Input) ಮತ್ತು Printer (Output) ಎರಡೂ ಸೇರಿರುತ್ತವೆ.
  • 5. Fax Machine (ಫ್ಯಾಕ್ಸ್) & Network Card (NIC).

🔤 ಲೈವ್ ಅನಿಮೇಷನ್ 6: ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ 'A' ಒತ್ತಿದಾಗ ನಡೆಯುವ ASCII ಬೈನರಿ ಪರಿವರ್ತನೆ

ಕೋಡಿಂಗ್ ಹೆಸರು ಪೂರ್ಣ ರೂಪ (Full Form) ಬಿಟ್ ಸಂಖ್ಯೆ ಅದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ? ಮತ್ತು ಪರೀಕ್ಷಾ ಪ್ರಮುಖಾಂಶಗಳು
1. BCD Binary Coded Decimal 4 Bits (1 Nibble) ಆರಂಭಿಕ ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ ಕೇವಲ ಗಣಿತದ ಅಂಕಿಗಳನ್ನು (0 ಯಿಂದ 9 ರವರೆಗೆ) ಪ್ರತಿನಿಧಿಸಲು ಬಳಸಲಾಗುತ್ತಿತ್ತು. ಪ್ರತಿ ಅಂಕಿಯನ್ನು 4 ಬಿಟ್‌ಗಳಲ್ಲಿ ಬರೆಯಲಾಗುತ್ತದೆ (ಉದಾ: $5 = 0101$). ಒಟ್ಟು ಸಂಯೋಜನೆಗಳು: $2^4 = 16$.
2. Standard ASCII American Standard Code for Information Interchange 7 Bits ಪರ್ಸನಲ್ ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ಬಳಕೆಯಾದ ಕೋಡ್. ಇದು 7 ಬಿಟ್ ಬಳಸುವುದರಿಂದ ಒಟ್ಟು $2^7 = 128$ ಅಕ್ಷರಗಳನ್ನು (0 ಯಿಂದ 127 ರವರೆಗೆ) ಪ್ರತಿನಿಧಿಸುತ್ತದೆ.
🎯 ಪರೀಕ್ಷೆಯಲ್ಲಿ ಕೇಳುವ ASCII ಸಂಖ್ಯೆಗಳು:
• ದೊಡ್ಡಕ್ಷರ 'A' = 65, 'B' = 66 ... 'Z' = 90
• ಸಣ್ಣಕ್ಷರ 'a' = 97, 'b' = 98 ... 'z' = 122
• ಅಂಕಿಗಳು '0' = 48 ರಿಂದ '9' = 57 | Space = 32.
3. Extended ASCII Extended ASCII Code 8 Bits (1 Byte) Standard ASCII ಯ 7 ಬಿಟ್‌ಗೆ ಇನ್ನೊಂದು ಬಿಟ್ ಸೇರಿಸಿ 8 ಬಿಟ್ ಮಾಡಲಾಯಿತು. ಇದರಿಂದ ಒಟ್ಟು $2^8 = 256$ ಅಕ್ಷರಗಳನ್ನು (0 ಯಿಂದ 255 ರವರೆಗೆ) ಪ್ರತಿನಿಧಿಸಲು ಸಾಧ್ಯವಾಯಿತು.
4. EBCDIC Extended Binary Coded Decimal Interchange Code 8 Bits ಇದು ಕೂಡಾ $2^8 = 256$ ಅಕ್ಷರಗಳನ್ನು ಹೊಂದಿದೆ. ಆದರೆ ಇದನ್ನು IBM ಕಂಪನಿಯು ತನ್ನ ಬೃಹತ್ Mainframe ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ ಬಳಸುವುದಕ್ಕಾಗಿ ಪ್ರತ್ಯೇಕವಾಗಿ ಅಭಿವೃದ್ಧಿಪಡಿಸಿತು.
5. ISCII Indian Script Code for Information Interchange 8 Bits ASCII ಯಲ್ಲಿ ಕೇವಲ ಇಂಗ್ಲಿಷ್ ಅಕ್ಷರಗಳಿದ್ದವು. ಭಾರತೀಯ ಭಾಷೆಗಳಾದ ಕನ್ನಡ, ಹಿಂದಿ (ದೇವನಾಗರಿ), ತೆಲುಗು, ತಮಿಳು ಮುಂತಾದ ಲಿಪಿಗಳನ್ನು ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಬಳಸಲು ಭಾರತ ಸರ್ಕಾರ (BIS) 1991 ರಲ್ಲಿ ರೂಪಿಸಿದ 8-ಬಿಟ್ ಕೋಡ್.

🏆 ಪರೀಕ್ಷೆಗೆ ಹೋಗುವ ಮುನ್ನ 10 ಚಿನ್ನದಂತಹ ಒನ್-ಲೈನರ್ ಸತ್ಯಗಳು (Golden Exam One-Liners):

1. ಚಾರ್ಲ್ಸ್ ಬ್ಯಾಬೇಜ್ (Charles Babbage): 1822 ರಲ್ಲಿ Difference Engine ಮತ್ತು 1837 ರಲ್ಲಿ Analytical Engine (ALU, Control, Memory ಪರಿಕಲ್ಪನೆ ಹೊಂದಿದ್ದ ಮೊದಲ ಯಂತ್ರ) ವಿನ್ಯಾಸಗೊಳಿಸಿದ್ದಕ್ಕಾಗಿ ಇವರನ್ನು "ಗಣಕಯಂತ್ರದ ಪಿತಾಮಹ" ಎನ್ನುತ್ತಾರೆ.
2. ಲೇಡಿ ಅಡಾ ಲವ್‌ಲೇಸ್ (Lady Ada Lovelace): Analytical Engine ಗಾಗಿ ಮೊದಲ ಬಾರಿಗೆ ಕೋಡಿಂಗ್ ಅಲ್ಗಾರಿದಮ್ ಬರೆದ ಕಾರಣ ಇವರನ್ನು "ವಿಶ್ವದ ಮೊದಲ ಕಂಪ್ಯೂಟರ್ ಪ್ರೋಗ್ರಾಮರ್" ಎನ್ನುತ್ತಾರೆ.
3. ಆಲನ್ ಟ್ಯೂರಿಂಗ್ (Alan Turing): Turing Machine ಸಿದ್ಧಾಂತ ನೀಡಿದ ಇವರನ್ನು "ಆಧುನಿಕ ಗಣಕಯಂತ್ರ ವಿಜ್ಞಾನದ ಮತ್ತು ಕೃತಕ ಬುದ್ಧಿಮತ್ತೆಯ (AI) ಪಿತಾಮಹ" ಎನ್ನುತ್ತಾರೆ.
4. ಮೊದಲ ಮೈಕ್ರೋಪ್ರೊಸೆಸರ್ (CPU Chip): 1971 ರಲ್ಲಿ ಇಂಟೆಲ್ ಕಂಪನಿಯ ಟೆಡ್ ಹಾಫ್ (Ted Hoff) ತಂಡ ನಿರ್ಮಿಸಿದ Intel 4004 (ಇದು 4-Bit ಪ್ರೊಸೆಸರ್ ಆಗಿತ್ತು). ಭಾರತದ ಮೊದಲ ಸ್ವದೇಶಿ ಮೈಕ್ರೋಪ್ರೊಸೆಸರ್: SHAKTI (IIT Madras).
5. ಸಿಪಿಯು ವೇಗದ ಅಳತೆ: ಸಾಮಾನ್ಯ ಕಂಪ್ಯೂಟರ್‌ಗಳ ವೇಗವನ್ನು GHz (Gigahertz) ಅಥವಾ MIPS (Million Instructions Per Second) ನಲ್ಲಿ ಅಳೆದರೆ, ಸೂಪರ್ ಕಂಪ್ಯೂಟರ್ ವೇಗವನ್ನು FLOPS ನಲ್ಲಿ ಅಳೆಯುತ್ತಾರೆ.
6. UPS (Uninterruptible Power Supply): ಕರೆಂಟ್ ಹೋದ ತಕ್ಷಣ ಕಂಪ್ಯೂಟರ್ ಆಫ್ ಆಗಿ RAM ನಲ್ಲಿರುವ ಕೆಲಸ ಅಳಿಸಿಹೋಗದಂತೆ ಬ್ಯಾಟರಿ ಬ್ಯಾಕಪ್ ನೀಡುವ ಸಾಧನ.
7. DMA (Direct Memory Access): ಸಿಪಿಯುಗೆ ತೊಂದರೆ ಕೊಡದೆ ಇನ್‌ಪುಟ್/ಔಟ್‌ಪುಟ್ ಸಾಧನಗಳು ನೇರವಾಗಿ RAM ಜೊತೆ ವೇಗವಾಗಿ ಡೇಟಾ ವರ್ಗಾಯಿಸಿಕೊಳ್ಳುವ ತಂತ್ರಜ್ಞಾನ.
8. GPU ಪೂರ್ಣ ರೂಪ: Graphics Processing Unit (ಇದರಲ್ಲಿರುವ ಮೆಮೊರಿಯನ್ನು VRAM - Video RAM ಎನ್ನುತ್ತಾರೆ).
9. CMOS ಪೂರ್ಣ ರೂಪ: Complementary Metal-Oxide Semiconductor.
10. POST ಪೂರ್ಣ ರೂಪ: Power-On Self-Test (ಇದು BIOS ROM ಒಳಗೆ ಇರುತ್ತದೆ).
