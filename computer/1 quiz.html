📘 ನಿಮ್ಮ ಸಂಪೂರ್ಣ ನೋಟ್ಸ್‌ನ ಪರೀಕ್ಷಾ ಸಾರಾಂಶ (One-Page Revision Sheet)

1. ಮೂಲ ವ್ಯಾಖ್ಯಾನ & ಪದದ ಮೂಲ:

• ಕಂಪ್ಯೂಟರ್: ವಿದ್ಯುನ್ಮಾನ ಸಾಧನ (Electronic Device) — ಡೇಟಾವನ್ನು Input ಆಗಿ ಸ್ವೀಕರಿಸಿ, Process ಮಾಡಿ, Output (ಮಾಹಿತಿ) ನೀಡುತ್ತದೆ ಮತ್ತು Store ಮಾಡುತ್ತದೆ.
• ಪದದ ಮೂಲ: ಲ್ಯಾಟಿನ್ ಭಾಷೆಯ "Computare" (ಅರ್ಥ: ಲೆಕ್ಕಾಚಾರ ಮಾಡುವುದು / To Calculate).
• COMPUTER ವಿಸ್ತರಣೆ: Commonly Operated Machine Particularly Used for Technical/Trade Education and Research.

2. ಕಾರ್ಯನಿರ್ವಹಣೆಯ 4 ಹಂತಗಳು & EDP:

• 4 ಹಂತಗಳು (IPOS): 1. Input (ಕೀಬೋರ್ಡ್, ಮೌಸ್) ➔ 2. Processing (CPU) ➔ 3. Output (ಮಾನಿಟರ್, ಪ್ರಿಂಟರ್) ➔ 4. Storage (ಹಾರ್ಡ್ ಡಿಸ್ಕ್, ಮೆಮೊರಿ).
• EDP (Electronic Data Processing): ಕಚ್ಚಾ ದತ್ತಾಂಶವನ್ನು (Raw Data) ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಉಪಯುಕ್ತ ಮಾಹಿತಿಯನ್ನಾಗಿ (Useful Information) ಪರಿವರ್ತಿಸುವ ಪ್ರಕ್ರಿಯೆ. (3 ಹಂತಗಳು: Input, Processing, Output).

3. ಪ್ರಮುಖ ವ್ಯಕ್ತಿಗಳು & ಕಂಪ್ಯೂಟರ್ ಮೆದುಳು:

• ಕಂಪ್ಯೂಟರ್ ಪಿತಾಮಹ: ಚಾರ್ಲ್ಸ್ ಬ್ಯಾಬೇಜ್ (Difference Engine - 1822, Analytical Engine - 1837).
• ಆಧುನಿಕ ಕಂಪ್ಯೂಟರ್ ವಿಜ್ಞಾನದ ಪಿತಾಮಹ: ಅಲಾನ್ ಟ್ಯೂರಿಂಗ್ (Turing Machine).
• ಮೊದಲ ಪ್ರೋಗ್ರಾಮರ್: ಲೇಡಿ ಅದಾ ಲವ್‌ಲೇಸ್. | ವಾಸ್ತುಶಿಲ್ಪದ ಪಿತಾಮಹ: ಜಾನ್ ವಾನ್ ನ್ಯೂಮನ್.
• ಮೆದುಳು (Brain): CPU (Central Processing Unit) — ಭಾಗಗಳು: ALU, CU, Registers.

4. ಪ್ರಮುಖ ಲಕ್ಷಣಗಳು (Characteristics):

• ವೇಗ (Speed): Nanoseconds (10⁻⁹ sec) ನಲ್ಲಿ ಲೆಕ್ಕಾಚಾರ (MIPS / FLOPS).
• ನಿಖರತೆ (Accuracy): 100% ನಿಖರ ಫಲಿತಾಂಶ — GIGO (Garbage In Garbage Out) ನಿಯಮದಡಿ.
• ಬಹುಮುಖಿ ಕಾರ್ಯ (Versatility): ಒಂದೇ ಸಮಯದಲ್ಲಿ ವಿವಿಧ ರೀತಿಯ ಕಾರ್ಯಗಳನ್ನು ನಿರ್ವಹಿಸುವ ಸಾಮರ್ಥ್ಯ.
• ದಣಿವರಿಯದ ದುಡಿಮೆ (Diligence): ಆಯಾಸ, ಬೇಸರವಿಲ್ಲದೆ ನಿರಂತರವಾಗಿ ಕೆಲಸ ಮಾಡುವುದು.
• ಮಿತಿಗಳು: ಸ್ವಂತ ಬುದ್ಧಿಮತ್ತೆ ಇಲ್ಲ (Zero IQ) ಮತ್ತು ಭಾವನೆಗಳಿಲ್ಲ.
