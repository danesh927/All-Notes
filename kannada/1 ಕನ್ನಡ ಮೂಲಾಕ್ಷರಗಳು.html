ಕನ್ನಡ ವರ್ಣಮಾಲೆ (ಮೂಲಾಕ್ಷರಗಳು)

ಭಾಷೆಯ ಮೂಲ ಘಟಕವೇ 'ವರ್ಣ' ಅಥವಾ 'ಅಕ್ಷರ'. ನಾಲಿಗೆಯಿಂದ ಉಚ್ಚರಿಸುವ ಧ್ವನಿರೂಪಗಳಿಗೆ ಬರವಣಿಗೆಯಲ್ಲಿ ನೀಡುವ ಸಂಕೇತಗಳೇ ಅಕ್ಷರಗಳು. ಅಕ್ಷರಗಳ ಕ್ರಮಬದ್ಧ ಜೋಡಣೆಯನ್ನು 'ವರ್ಣಮಾಲೆ' ಅಥವಾ 'ಅಕ್ಷರಮಾಲೆ' ಎನ್ನುವರು.

📜 ಕೇಶಿರಾಜನ 'ಶಬ್ದಮಣಿದರ್ಪಣ' ಸೂತ್ರ (KAS / UPSC ಐಚ್ಛಿಕ ಕನ್ನಡ):

"ಶುದ್ಧಗೆಯೊಳ್ ನಾಲ್ವತ್ತೇಳು ಅಕ್ಷರಂ..." — ಪ್ರಾಚೀನ ಕನ್ನಡದಲ್ಲಿ ೪೭ ಶುದ್ಧಾಕ್ಷರಗಳು (ಸಂಸ್ಕೃತದ ೫೨ ಅಕ್ಷರಗಳಿಂದ ಕೆಲವನ್ನು ಬಿಟ್ಟು, ದ್ರಾವಿಡ ವಿಶೇಷ ಅಕ್ಷರಗಳಾದ ಱ, ಳ, ೞ ಸೇರಿಸಿ) ಇದ್ದವು. ಪ್ರಸ್ತುತ ಆಧುನಿಕ ಕನ್ನಡ ವರ್ಣಮಾಲೆಯಲ್ಲಿ ಒಟ್ಟು ೪೯ (49) ಅಕ್ಷರಗಳಿವೆ.

🔬 ಸಂಧಿಸ್ವರಗಳ (ಸಂಯುಕ್ತ ಸ್ವರ) ನಿರ್ಮಾಣ

KAS / FDA ಪ್ರಶ್ನೆ

ಸಂಸ್ಕೃತ ವ್ಯಾಕರಣದ ಪ್ರಕಾರ ಏ, ಐ, ಓ, ಔ ಎಂಬ ನಾಲ್ಕು ದೀರ್ಘಸ್ವರಗಳು ಎರಡು ಭಿನ್ನ ಸ್ವರಗಳ ಸಂಧಿಸುವಿಕೆಯಿಂದ ಹುಟ್ಟಿವೆ. ಆದ್ದರಿಂದ ಇವಕ್ಕೆ 'ಸಂಧಿಸ್ವರಗಳು' ಎನ್ನುತ್ತಾರೆ:

* ಸೂಚನೆ: ಐ ಮತ್ತು ಔ ಅಕ್ಷರಗಳಿಗೆ ಸಮಾನವಾದ ಹ್ರಸ್ವಸ್ವರಗಳಿಲ್ಲ. ಕನ್ನಡದಲ್ಲಿ 'ಎ' ಮತ್ತು 'ಒ' ಹ್ರಸ್ವಗಳಿವೆ (ಇವು ದ್ರಾವಿಡ ಭಾಷೆಯ ವೈಶಿಷ್ಟ್ಯ).

ಅಧ್ಯಾಯ ೩ : ಯೋಗವಾಹಗಳು (೨)

ಯೋಗವಾಹಗಳು : ಅನುಸ್ವಾರ (ಂ) ಮತ್ತು ವಿಸರ್ಗ (ಃ)

"ಯೋಗಂ ವಹಂತಿ ಇತಿ ಯೋಗವಾಹಾಃ" — ಅಂದರೆ ಸ್ವರದ ಸಂಬಂಧವನ್ನು ಪಡೆದುಕೊಂಡು ಮಾತ್ರ ಉಚ್ಚಾರಣೆಗೊಳ್ಳುವ ವರ್ಣಗಳು.

ಯೋಗವಾಹ - ೧

ಅನುಸ್ವಾರ ( ಂ - ಸೊನ್ನೆ )

ಇನ್ನೊಂದು ಹೆಸರು: 'ಬಿಂದು' ಅಥವಾ 'ಪೂರ್ಣಬಿಂದು'

ಸ್ವರದ ಬೆನ್ನಹಿಂದೆಯೇ (ಅನು = ಹಿಂದೆ, ಸ್ವಾರ = ಸ್ವರವನ್ನು ಹೊಂದಿಕೊಂಡು) ಮೂಗಿನ ಸಹಾಯದಿಂದ ಉಚ್ಚರಿಸುವ ಧ್ವನಿ. ಇದಕ್ಕೆ ಸ್ವತಂತ್ರ ಉಚ್ಚಾರಣೆ ಇಲ್ಲ; ಅ + ಂ = ಅಂ ಎಂದೇ ಉಚ್ಚರಿಸಬೇಕು.

🎯 ಸ್ಪರ್ಧಾತ್ಮಕ ಪರೀಕ್ಷೆಯ ಪ್ರಮುಖ ನಿಯಮ:

ವರ್ಗೀಯ ವ್ಯಂಜನಗಳ ಮುಂದೆ ಅನುಸ್ವಾರ ಬಂದರೆ, ಅದು ಆ ವರ್ಗದ ಅನುನಾಸಿಕದಂತೆ ಉಚ್ಚರಿಸಲ್ಪಡುತ್ತದೆ!

ಅಂಗ = ಅ + ङ् + ಗ (ಕ-ವರ್ಗ)
ಪಂಚ = ಪ + ञ् + ಚ (ಚ-ವರ್ಗ)
ಗಂಟೆ = ಗ + ण् + ಟೆ (ಟ-ವರ್ಗ)
ಸಂತ = ಸ + न् + ತ (ತ-ವರ್ಗ)
ಯೋಗವಾಹ - ೨

ವಿಸರ್ಗ ( ಃ - ಎರಡು ಸೊನ್ನೆ )

ಉಚ್ಚಾರಣಾ ಸ್ಥಾನ: ಕಂಠ್ಯ (ಗಂಟಲಿನಿಂದ ಉಸಿರು ಹೊರಹಾಕುವುದು)

'ವಿಸರ್ಗ' ಎಂದರೆ ಹೊರಹಾಕುವುದು (ಉಸಿರನ್ನು ಬಿಡುವುದು). ಇದು ಸಾಮಾನ್ಯವಾಗಿ 'ಹ್' ಧ್ವನಿಯಂತೆ ಕೇಳಿಸುತ್ತದೆ. ಇದು ಸಂಸ್ಕೃತ ತತ್ಸಮ ಪದಗಳಲ್ಲಿ ಮಾತ್ರ ಕಂಡುಬರುತ್ತದೆ; ಅಚ್ಚಕನ್ನಡ ಪದಗಳಲ್ಲಿ ವಿಸರ್ಗವಿಲ್ಲ!

🎯 KAS / FDA / PSI ಪರೀಕ್ಷಾ ಮುಖ್ಯಾಂಶ:

ವಿಸರ್ಗವಿರುವ ಯಾವುದೇ ಪದವು ಅಚ್ಚಕನ್ನಡ ಪದವಲ್ಲ, ಅದು ನೂರಕ್ಕೆ ನೂರರಷ್ಟು ಸಂಸ್ಕೃತದಿಂದ ಬಂದ ಪದವಾಗಿರುತ್ತದೆ (ಉದಾ: ದುಃಖ, ಅಂತಃಪುರ, ತಪಃಫಲ, ಮನಃಶಾಂತಿ, ಪ್ರಾತಃಕಾಲ).

ಕೇಶಿರಾಜನ ಮತ: ಶಬ್ದಮಣಿದರ್ಪಣದಲ್ಲಿ ಕೇಶಿರಾಜನು ಸೊನ್ನೆ (ಂ), ವಿಸರ್ಗ (ಃ), ಜಿಹ್ವಾಮೂಲೀಯ ಮತ್ತು ಉಪಧ್ಮಾನೀಯಗಳನ್ನು 'ಯೋಗವಾಹಗಳು' ಎಂದು ಕರೆದಿದ್ದಾನೆ.
ಅಧ್ಯಾಯ ೪ : ವ್ಯಂಜನಗಳ (೩೪) ವಿಜ್ಞಾನ

ವರ್ಗೀಯ (೨೫) ಮತ್ತು ಅವರ್ಗೀಯ (೯) ವ್ಯಂಜನಗಳ ಜಾಲರಿ

ಕೆಳಗಿನ ಫಿಲ್ಟರ್ ಬಟನ್‌ಗಳನ್ನು ಒತ್ತಿ ಅಲ್ಪಪ್ರಾಣ, ಮಹಾಪ್ರಾಣ, ಅನುನಾಸಿಕ, ಶ್ವಾಸ (ಅಘೋಷ) ಮತ್ತು ನಾದ (ಘೋಷ) ಅಕ್ಷರಗಳನ್ನು ತಕ್ಷಣ ಗುರುತಿಸಿ!

ಅ) ವರ್ಗೀಯ ವ್ಯಂಜನಗಳು (೨೫) - ಸ್ಪರ್ಶ ವ್ಯಂಜನಗಳು

ಅಕ್ಷರದ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ ಧ್ವನಿ ಕೇಳಿ 🔊

ವರ್ಗೀಯ ವ್ಯಂಜನಗಳ ವರ್ಗೀಕರಣ

'ಪ್ರಾಣ' ಎಂದರೆ ಉಸಿರು. ವ್ಯಂಜನಗಳನ್ನು ಉಚ್ಚರಿಸುವಾಗ ಶ್ವಾಸಕೋಶದಿಂದ ಹೊರಬರುವ ಉಸಿರಿನ ಪ್ರಮಾಣವನ್ನು ಆಧರಿಸಿ ಅಲ್ಪಪ್ರಾಣ ಮತ್ತು ಮಹಾಪ್ರಾಣಗಳೆಂದು ವಿಂಗಡಿಸಲಾಗಿದೆ.

🌱 ಅಲ್ಪಪ್ರಾಣ (ಕಡಿಮೆ ಉಸಿರು) ಕ, ಗ, ಚ, ಜ, ಟ, ಡ...
🔥 ಮಹಾಪ್ರಾಣ (ಹೆಚ್ಚು ಉಸಿರು / ಒತ್ತು) ಖ, ಘ, ಛ, ಝ, ಠ, ಢ...
👃 ಅನುನಾಸಿಕ (ಮೂಗಿನ ಸಹಾಯ) ಙ, ಞ, ಣ, ನ, ಮ

ಬಾಯಿಯ ಜೊತೆಗೆ ಮೂಗಿನ ಹೊಳ್ಳೆಯ ಮೂಲಕ ಉಸಿರು ಹೊರಬರುತ್ತದೆ.

🎓 KAS / UPSC ವಿಶೇಷಾಂಶ (ಶ್ವಾಸ vs ನಾದ):

• ಶ್ವಾಸಾಕ್ಷರಗಳು (ಅಘೋಷ - Voiceless): ಗಂಟಲಿನ ಧ್ವನಿಪೆಟ್ಟಿಗೆಯ ತಂತಿಗಳು ಕಂಪಿಸದೆ ಕೇವಲ ಉಸಿರಿನಿಂದ ಹುಟ್ಟುವ ಅಕ್ಷರಗಳು (ಪ್ರತಿ ವರ್ಗದ 1, 2ನೇ ಅಕ್ಷರ + ಶ, ಷ, ಸ = ಒಟ್ಟು 13).

• ನಾದಾಕ್ಷರಗಳು (ಘೋಷ - Voiced): ಧ್ವನಿಪೆಟ್ಟಿಗೆಯಲ್ಲಿ ನಾದ/ಕಂಪನ ಉಂಟಾಗಿ ಹುಟ್ಟುವ ಅಕ್ಷರಗಳು (ಪ್ರತಿ ವರ್ಗದ 3, 4, 5ನೇ ಅಕ್ಷರ + ಯ, ರ, ಲ, ವ, ಹ, ಳ + ಎಲ್ಲಾ ಸ್ವರಗಳು).

ಯ ರಿಂದ ಳ ವರೆಗೆ (೯ ಅಕ್ಷರಗಳು)

ಆ) ಅವರ್ಗೀಯ ವ್ಯಂಜನಗಳು (೯) — ವರ್ಗಕ್ಕೆ ಸೇರದ ವ್ಯಂಜನಗಳು

ಇವುಗಳನ್ನು ಕ-ವರ್ಗ, ಚ-ವರ್ಗಗಳಂತೆ ನಿರ್ದಿಷ್ಟ ಗುಂಪುಗಳಾಗಿ (ವರ್ಗಗಳಾಗಿ) ವಿಂಗಡಿಸಲು ಸಾಧ್ಯವಿಲ್ಲದ ಕಾರಣ 'ಅವರ್ಗೀಯ ವ್ಯಂಜನಗಳು' ಎನ್ನುವರು. ಆದರೆ ಧ್ವನಿಶಾಸ್ತ್ರದ ಪ್ರಕಾರ ಇವುಗಳಲ್ಲಿ ೩ ಮುಖ್ಯ ವಿಭಾಗಗಳಿವೆ:

೧. ಅಂತಸ್ಥಗಳು (ಅರ್ಧಸ್ವರಗಳು)

4 ಅಕ್ಷರಗಳು

ಸ್ವರ ಮತ್ತು ವ್ಯಂಜನಗಳ ನಡುವೆ ನಿಲ್ಲುವಂತಹ (ಅಂತಃ = ನಡುವೆ ಇರುವ) ಕೋಮಲ ವ್ಯಂಜನಗಳು.

೨. ಊಷ್ಮಾಕ್ಷರಗಳು (ಘರ್ಷಣಾಕ್ಷರ)

4 ಅಕ್ಷರಗಳು

'ಊಷ್ಮ' ಎಂದರೆ ಬಿಸಿ ಉಸಿರು. ಬಾಯಿಯ ಒಳಭಾಗದಲ್ಲಿ ಗಾಳಿ ಉಜ್ಜಿಕೊಂಡು ಬಿಸಿ ಉಸಿರಿನಂತೆ ಹೊರಬರುವ ಅಕ್ಷರಗಳು.

೩. ದ್ರಾವಿಡ ವಿಶೇಷ ಅಕ್ಷರ (ಕುಳ)

1 (+2 ಪ್ರಾಚೀನ)

'ಳ' ಅಚ್ಚಕನ್ನಡ/ದ್ರಾವಿಡ ವಿಶೇಷ ಅಕ್ಷರ. ಹಳಗನ್ನಡದಲ್ಲಿ ಱ (ರಳ) ಮತ್ತು ೞ (ಕ್ಷಳ/ಳ್ಹ) ಕೂಡ ಬಳಕೆಯಲ್ಲಿದ್ದವು.

ಅಧ್ಯಾಯ ೫ : ಧ್ವನಿಶಾಸ್ತ್ರ ಮತ್ತು ಉಚ್ಚಾರಣಾ ಸ್ಥಾನಗಳು

ಅಕ್ಷರಗಳ ಉತ್ಪತ್ತಿ ಸ್ಥಾನಗಳು (Interactive Vocal Tract)

ಶ್ವಾಸಕೋಶದಿಂದ ಹೊರಟ ಗಾಳಿಯು ಗಂಟಲು, ದವಡೆ, ಅಂಗುಳ, ಒಸಡು, ಹಲ್ಲು, ತುಟಿ ಮತ್ತು ಮೂಗುಗಳಲ್ಲಿ ತಡೆದು ಅಕ್ಷರಗಳಾಗಿ ಹೊರಹೊಮ್ಮುತ್ತದೆ. ಚಿತ್ರದಲ್ಲಿರುವ ಬಿಂದುಗಳ ಮೇಲೆ ಅಥವಾ ಬಲಭಾಗದ ಸ್ಥಾನಗಳ ಮೇಲೆ ಕ್ಲಿಕ್ ಮಾಡಿ!

ಮಾನವನ ಧ್ವನ್ಯಂಗಗಳ ನಕ್ಷೆ (ಕ್ಲಿಕ್ ಮಾಡಿ)
💡 ಚಿತ್ರದ ಮೇಲಿರುವ ಬಣ್ಣದ ಬಿಂದುಗಳನ್ನು ಒತ್ತಿರಿ
ಸೂತ್ರ: ಅಕುಹವಿಸರ್ಜನೀಯಾನಾಂ ಕಂಠಃ

೧. ಕಂಠ್ಯ ವರ್ಣಗಳು (ಕಂಠಸ್ಥಾನ / ಗಂಟಲು)

ಶ್ವಾಸಕೋಶದಿಂದ ಬರುವ ಗಾಳಿಯು ನೇರವಾಗಿ ಗಂಟಲಿನಲ್ಲಿ (ಕಂಠದಲ್ಲಿ) ತಡೆದು ಉತ್ಪತ್ತಿಯಾಗುವ ಅಕ್ಷರಗಳನ್ನು 'ಕಂಠ್ಯ ವರ್ಣಗಳು' ಎನ್ನುತ್ತಾರೆ.

ಈ ಸ್ಥಾನದಲ್ಲಿ ಹುಟ್ಟುವ ಅಕ್ಷರಗಳು:
ಅಧ್ಯಾಯ ೬ : ಸಂವಾದಾತ್ಮಕ ಪ್ರಯೋಗಶಾಲೆ (Interactive Lab)

ಗುಣಿತಾಕ್ಷರ ಮತ್ತು ಸಂಯುಕ್ತಾಕ್ಷರ (ಒತ್ತಕ್ಷರ) ನಿರ್ಮಾಣ

ವ್ಯಂಜನಕ್ಕೆ ಸ್ವರ ಸೇರಿದಾಗ ಗುಣಿತಾಕ್ಷರ (ಕಾಗುಣಿತ) ಹುಟ್ಟುತ್ತದೆ. ಎರಡು ಅಥವಾ ಹೆಚ್ಚಿನ ವ್ಯಂಜನಗಳಿಗೆ ಒಂದು ಸ್ವರ ಸೇರಿದಾಗ ಸಂಯುಕ್ತಾಕ್ಷರ (ಒತ್ತಕ್ಷರ) ಹುಟ್ಟುತ್ತದೆ.

ಪ್ರಯೋಗಶಾಲೆ - ೧

ಗುಣಿತಾಕ್ಷರ (ಕಾಗುಣಿತ) ಸಂಯೋಜಕ

ವ್ಯಂಜನ + ಸ್ವರ = ಗುಣಿತಾಕ್ಷರ

⚠️ ಪರೀಕ್ಷಾ ನಿಯಮ: ಗುಣಿತಾಕ್ಷರಗಳಲ್ಲಿ ಯೋಗವಾಹಗಳನ್ನು (ಅಂ, ಅಃ) ಸೇರಿಸುವುದಿಲ್ಲ; ಕೇವಲ 13 ಸ್ವರಗಳು ಮಾತ್ರ ಸೇರುತ್ತವೆ. ಆದರೆ ಸಾಂಪ್ರದಾಯಿಕ ಕಾಗುಣಿತದಲ್ಲಿ (ಕ ರಿಂದ ಕಃ ವರೆಗೆ) 15 ಅಕ್ಷರಗಳಿರುತ್ತವೆ.

ಗುಣಿತಾಕ್ಷರ ಸಮೀಕರಣ ಮತ್ತು ಚಿಹ್ನೆಯ ಹೆಸರು
ಕ್ + ಅ = ಕ
ಸ್ವರ ಚಿಹ್ನೆ: ತಲೆಕಟ್ಟು (ಮೂಲ ವ್ಯಂಜನಕ್ಕೆ 'ಅ' ಸೇರಿದಾಗ ತಲೆಕಟ್ಟು ಬರುತ್ತದೆ)
ಪ್ರಯೋಗಶಾಲೆ - ೨

ಸಂಯುಕ್ತಾಕ್ಷರ (ಒತ್ತಕ್ಷರ) ಪರೀಕ್ಷಕ

ಸಜಾತೀಯ vs ವಿಜಾತೀಯ
೧. ಸಜಾತೀಯ ಸಂಯುಕ್ತಾಕ್ಷರ (ದ್ವಿತ್ವ)

ಒಂದೇ ಜಾತಿಯ ಎರಡು ವ್ಯಂಜನಗಳು ಸೇರಿ ಆಗುವ ಒತ್ತಕ್ಷರ. (ಉದಾ: ಕ್ + ಕ್ + ಅ = ಕ್ಕ, ಅಮ್ಮ, ಅಜ್ಜ, ಹಗ್ಗ)

೨. ವಿಜಾತೀಯ ಸಂಯುಕ್ತಾಕ್ಷರ

ಬೇರೆ ಬೇರೆ ಜಾತಿಯ ವ್ಯಂಜನಗಳು ಸೇರಿ ಆಗುವ ಒತ್ತಕ್ಷರ. (ಉದಾ: ಕ್ + ಷ್ + ಅ = ಕ್ಷ, ಭಕ್ತಿ, ಜ್ಞಾನ, ಕಾರ್ಯ)

ವಿಜಾತೀಯ ಸಂಯುಕ್ತಾಕ್ಷರ ಉದಾಹರಣೆ: ಕ್ಷಮೆ, ಅಕ್ಷರ
ಕ್ + ಷ್ + ಅ = ಕ್ಷ

💡 ನೆನಪಿಡಿ: 'ಕ್ಷ' ಎಂಬುದು ಮೂಲಾಕ್ಷರವಲ್ಲ! ಇದು ಕ-ಕಾರ (ಕ್), ಷ-ಕಾರ (ಷ್) ಮತ್ತು ಅ-ಕಾರಗಳ ಸಂಯೋಗದಿಂದಾದ ವಿಜಾತೀಯ ಸಂಯುಕ್ತಾಕ್ಷರ.

ಅಧ್ಯಾಯ ೭ : UPSC / KAS / FDA / SDA / PSI ಬ್ರಹ್ಮಾಸ್ತ್ರ

ಸ್ಪರ್ಧಾತ್ಮಕ ಪರೀಕ್ಷೆಗಳ ವಿಶೇಷ ತುಲನಾತ್ಮಕ ಕೋಷ್ಟಕ

ಕೇಶಿರಾಜನ 'ಶಬ್ದಮಣಿದರ್ಪಣ', ನಾಗವರ್ಮನ 'ಕರ್ಣಾಟಕ ಭಾಷಾಭೂಷಣ' ಹಾಗೂ ಆಧುನಿಕ ಕನ್ನಡ ವರ್ಣಮಾಲೆಯ ನಡುವಿನ ವ್ಯತ್ಯಾಸಗಳು.

೧. ಕೇಶಿರಾಜನ ಶುದ್ಧಗೆ (೪೭ ಅಕ್ಷರ)

ಶಬ್ದಮಣಿದರ್ಪಣ

ಕ್ರಿ.ಶ. 1260ರಲ್ಲಿ ಕೇಶಿರಾಜನು ರಚಿಸಿದ 'ಶಬ್ದಮಣಿದರ್ಪಣ' ಕನ್ನಡದ ಅತ್ಯಂತ ಪ್ರಮಾಣಬದ್ಧ ವ್ಯಾಕರಣ ಗ್ರಂಥ. ಇವನ ಪ್ರಕಾರ ಸಂಸ್ಕೃತದ ೫೨ ಅಕ್ಷರಗಳಲ್ಲಿ ಕನ್ನಡಕ್ಕೆ ಒಗ್ಗದ ಅಕ್ಷರಗಳನ್ನು ಕಳೆದು, ದ್ರಾವಿಡ ವಿಶೇಷಗಳನ್ನು ಸೇರಿಸಿದಾಗ ೪೭ ಶುದ್ಧಾಕ್ಷರಗಳು ಉಳಿಯುತ್ತವೆ:

  • • ಸ್ವರಗಳು (14): ಅ, ಆ, ಇ, ಈ, ಉ, ಊ, ಋ, ೠ, ಎ, ಏ, ಐ, ಒ, ಓ, ಔ (ಌ, ೡ ಕೈಬಿಡಲಾಗಿದೆ).
  • • ವರ್ಗೀಯ ವ್ಯಂಜನ (25): ಕ ವರ್ಗದಿಂದ ಪ ವರ್ಗದವರೆಗೆ (25).
  • • ಅವರ್ಗೀಯ (8): ಯ, ರ, ಲ, ವ, ಶ, ಷ, ಸ, ಹ (8).
  • • ದೇಸಿಯ ಅಕ್ಷರಗಳು (5): ಎ, ಒ (ಹ್ರಸ್ವ) ಹಾಗೂ ಱ (ರಳ), ಳ (ಕುಳ), ೞ (ಕ್ಷಳ) ಕನ್ನಡದ ವಿಶೇಷ ವರ್ಣಗಳು.

೨. ಅಚ್ಚಕನ್ನಡದಲ್ಲಿ ಇಲ್ಲದ ಅಕ್ಷರಗಳು

KAS / FDA ಟ್ರಿಕ್ಸ್

ಕನ್ನಡ ವರ್ಣಮಾಲೆಯ 49 ಅಕ್ಷರಗಳಲ್ಲಿ ಕೆಲವು ಅಕ್ಷರಗಳು ಕೇವಲ ಸಂಸ್ಕೃತದಿಂದ ಬಂದ (ತತ್ಸಮ) ಪದಗಳನ್ನು ಬರೆಯಲು ಮಾತ್ರ ಬಳಕೆಯಾಗುತ್ತವೆ. ಈ ಕೆಳಗಿನ ಅಕ್ಷರಗಳಿರುವ ಪದಗಳು ಸಂಸ್ಕೃತ ಪದಗಳು:

೧. ಋ (ಸ್ವರ): ಋಷಿ, ಋತು, ಕೃಷಿ, ಪಿತೃ — ಇವೆಲ್ಲವೂ ಸಂಸ್ಕೃತ ಪದಗಳು.
೨. ವಿಸರ್ಗ (ಃ): ದುಃಖ, ಅಂತಃಕರಣ, ಪುನಃ — ಸಂಸ್ಕೃತ ಪದಗಳು.
೩. ಮಹಾಪ್ರಾಣಾಕ್ಷರಗಳು (10): ಖ, ಘ, ಛ, ಝ, ಠ, ಢ, ಥ, ಧ, ಫ, ಭ (ಅಚ್ಚಕನ್ನಡದ ಕೆಲವೇ ಅನುಕರಣ ಶಬ್ದಗಳನ್ನು ಹೊರತುಪಡಿಸಿ ಉಳಿದೆಲ್ಲವೂ ಸಂಸ್ಕೃತ).
೪. ಶ ಮತ್ತು ಷ (ಊಷ್ಮ): ಶಾಂತಿ, ಶಂಕರ, ಕಷ್ಟ, ಪುರುಷ — ಸಂಸ್ಕೃತ ಪದಗಳು.

೩. ಅಂಕಿ-ಅಂಶಗಳ ಸಾರಾಂಶ (One-Liners)
